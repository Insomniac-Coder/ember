# Classification of the 0.9.15_Hardened_1 -> 0.9.20_Hardened_12 rule changes, areas 01, 02, 08

Method: each rule's diff read (whole new text where hard), work item from the gap file's "Completes:" lines and rule row, milestone from MILESTONES.md, built-code check by Grep in `compiler/` and `std/`. Milestones: A1-2..A1-4, A1-6..A1-8, A1-12 = M3; A1-5, A1-9..A1-11 = M4; A1-17 = M2 (first half) + M9; A1-13..A1-16 = M10; A1-18, A1-19 = M5; A1-20 = M11; A1-21, A1-22 = M6a; A2-2..A2-8, A2-15 = M5; A2-9 = M2; A2-10, A2-13 = M6a; A2-11 = M6b; A2-12, A2-14 = M6c; A8-1..A8-5, A8-7, A8-8 = M14. No rule in these three diff files is `new`; every one existed in 0.9.15.

Note on the starting state: the tree already enforces the 0.9.20 `owns` word at calls (typeck `lib.rs:58311` `check_call_word`, `:58522` `check_argument_by`, `missing_owns_word`, `taken_value`; constructor argument rule `lib.rs:58861`; `b = owns n` at `lib.rs:47014`; function-from-a-variable lent, `lent_callable_args`, `lib.rs:58330`). So the `owns`-at-the-call rows below are "already built", more than the brief says.

## Needs the lead's eye

1. **A8-7 is reversed by the spec.** The gap item says "delete `lend_named_callable` ... so a named function given to `owns f: F` is handed over". 0.9.20 (FN-2a, STD-19, ODR-240, verdict 150) says a function from a variable is lent to a parameter of a type-parameter type with a function bound, so `h` stays the caller's. The tree already lends (`lib.rs:58330`). A8-7's first bullet must go.
2. **A8-2 (one-element tuples `(A,)`) is dead** (verdict 115): `reg.view[A, B]()` uses variadic generics, TYP-47 (area 7's rule). No gap item builds variadic generics; ECS-3, ECS-4, STD-9, STD-18, STD-26 all wait on it, and MILESTONES.md already calls it "a new piece of compiler work before M14". Needs an owner/item and milestone (suggest between M11 and M14).
3. **`type_identity` -> `type_id`.** The spec text has no `type_identity` and ECS-2 names `std.core.type_id[T]()`. The built intrinsic and `std/src/core.em` (AnyError) use `type_identity`. Confirm the rename is covered by area 7's TYP-44/44a rows, else it is new work for M1-style respell.
4. **The tree is ahead of the brief on `owns` at calls** (FN-2a, OWN-9, STD-19 rows): the call-word checks, constructor rule and lending exist (`lib.rs:58311`, `:58522`, `:58861`). Only A1-2's "not built" fallback in `synth_owns` (`lib.rs:47014-47055`) remains for OWN-9.
5. **Interface-file schema grows** (OWN-13, ALC-1, MONO-10, LT-1, BRW-21: BLD-14 items 8, 9, 11, 14, 15, and pub function bodies). No gap item lists these records; I mapped them to A4-3 (M2), which is already built in part, so the M2 schema needs room for them even though they are consumed in M4/M6a/M9/M10.
