the compiler works it out from the code (R5 lines 362-384), a call through a function value by every

verdicts 63 and 64 asked for is void), and a refusal that rested on a function type's `changes Player` or
`changes Node` now rests on the function the program stores there. A `drop` writes `fn drop():`
(verdicts 69, 86). Messages give every line they replace, and their fixes compile (R18, verdict 73).
