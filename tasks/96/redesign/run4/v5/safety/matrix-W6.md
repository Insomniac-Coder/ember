How every result is verified once the model is built: the conformance runner (`ember test`,
`compiler/ember_driver/src/test_runner.rs`) compiles each file and compares the output with its `#$`
lines: for `compile-fail` the code and the message of the `#$ error` on its line, and `#$ help:`; for
`compile-pass` the `#$ warning` lines; for `run-pass` the stdout lines in order; for `run-fail` the
stdout before the stop and the start of the stop's text (`#$ panics:`). The thread tests are also run
once under ThreadSanitizer and the trampoline, callback, cast and `into_raw` tests under
AddressSanitizer (C backend, Clang), which must report nothing: that shows the run-time checks stop the
program before memory is touched wrongly, and that the compile-time checks leave no data race.
