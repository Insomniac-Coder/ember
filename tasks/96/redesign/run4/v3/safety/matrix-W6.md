# Safety matrix, writer W6: R14, R15, R16 and the C side

Writer W6 of safety validation (b). Rules: R14 (interface values, kind tests, casts, and verdict 46's
`dyn ... changes`), R15 (threads), R16 (`unsafe`), and the C side of R12 and R15 (kept callbacks,
`@ffi(no_callbacks)`, the checked trampoline; verdicts 31, 39). Sources: `V3/rules.md` (cited as
`rules.md:N`), `V3/vocabulary.md`, `V3/area-B.md` (AN-22), `V3/area-D.md` (AN-66 to AN-70),
`V3/area-E.md` (AN-71 to AN-84), the verdicts in `V3/inputs/JOB.md`. Nothing was compiled or run.

The tests are in `V3/conformance/R14/` (38), `V3/conformance/R15/` (97, and the C library of the
trampoline run tests, `kept_events.c` with `kept_events.h`) and `V3/conformance/R16/` (14): 149 tests.
Line numbers inside expected messages are the test file's own lines (checked by
`target/redesign5/W6/check_lines.py`, which prints the text of every line a message names; the files
are written by `target/redesign5/W6/gen.py` from `tests_r14.py`, `tests_r15.py`, `tests_r15_c.py`,
`tests_r16.py`). Where a guarantee is also another writer's, the row names that writer's test
(`R9/...`, W4).

How every result is verified once the model is built: the conformance runner (`ember test`,
`compiler/ember_driver/src/test_runner.rs`) compiles each file and compares the output with its `#$`
lines: for `compile-fail` the code and the message of each `#$ error` on its line, and `#$ help:`; for
`compile-pass` the `#$ warning` lines; for `run-pass` the stdout lines in order; for `run-fail` the
stdout before the stop and the start of the panic. The thread tests are also run once under
ThreadSanitizer and the trampoline and cast tests under AddressSanitizer (C backend, Clang), which must
report nothing: that shows the run-time checks stop the program before memory is touched wrongly, and
that the compile-time checks leave no data race.

"Enforcing part": parser `compiler/ember_parser/src/body.rs`, `decls.rs` (lexer
`compiler/ember_lexer/src/token.rs`); type checker `compiler/ember_typeck/src/lib.rs` (old spellings in
`compiler/ember_typeck/src/habits.rs`); borrow check = the MIR passes of `compiler/ember_analysis/src/`
(`borrows.rs`, `regions.rs`, `stores.rs` for E3026, `coroutines.rs` for E2221, `static_safe.rs` for
E4030, `effects.rs` for today's effect sets, the nearest existing work to checking `changes`); MIR
lowering `compiler/ember_mir/src/lower.rs` (`lower_class_downcast`), `compiler/ember_mir/src/parallel.rs`;
code generator `compiler/ember_codegen_c/src/lib.rs` (the downcast stop, `AssertKind::Downcast`; the C
trampolines), `compiler/ember_codegen_llvm/src/ffi.rs` and `dispatch.rs`; interface files
`compiler/ember_build/src/interface.rs` (R17); runtime `runtime/ember_rt/src/ember_rt.c`
(`ember_downcast`, locks, thread checks). New codes (E2106, E2113, E2105, E5069, E7007, E7008,
E7012 to E7018) are emitted nowhere today (`grep` over `compiler/`); the row names the part that would.

## Open points (each is in the form's `for_owner`)

1. A call through a `fn() changes Log` value inside a walk of `log.lines` under `log`'s lock has two codes: section 3 gives it E3020 (`rules.md:837`, second message) and R15 / E7018 cover every such call inside the lock (`rules.md:710-715`, `rules.md:963`); R18 asks for one message (`rules.md:758`). The test expects E3020.
2. A scoped task that changes a list its parent walks: R15 says E7007 (`rules.md:696`), R8 (c) lists "a `spawn` whose thread changes it" under E3020 (`rules.md:360`). The test expects E7007. For unscoped threads the E3020 case seems unreachable: every place another thread may change is reached only under its lock or atomically (E7012 to E7015).
3. Verdict 52's and AN-76's line `thread.spawn(fn() changes RESULTS: worker(r))` uses the loop name `r` with no capture word, which R15's third point refuses for an unscoped thread (E7004, `rules.md:704-705`). The test writes `with copy of r`.
4. Whether `stats.total += e` (a field of a captured class object) is a reduction: R15 lists `total += e` among reductions (`rules.md:701`) and the E7007 row refuses `stats.total` (`rules.md:874`). The test expects E7007.
5. The rules give no text for the stop of a failed `cast` (`rules.md:680`), nor for the trampoline's stop of a call after `unregister` (AN-78 says it "stops with the callback's name"); the tests use today's `invalid downcast` and a written start. The trampoline's thread check is debug-only today (`FFI-33b`); AN-78 describes it with no profile.
6. L3015's message (`rules.md:884-885`) gives `@safety("p points to four readable bytes")`, a promise the compiler cannot know (R18: "A message says only what the compiler knows", `rules.md:761`).
7. Messages the rules leave unwritten and these tests write to R18: E2020 for a kind test between unrelated types; E3027 for a `ref mut` kind-test name of a read-only parameter; E2105 and E3020 for a `dyn ... changes LOG`; E7007 for a task changing its parent's walked list; E7013 for a read; E7018 for a scope's end; E2105 for channels; E3028 for a channel end; E4030 for `assert_disjoint`.
8. The trampoline's tag `0x4080` is AN-78's (area E), not `V3/rules.md`'s, which says only "a tagged `{slot, generation}` number, never an address" (`rules.md:726-727`); `run_c_holds_a_tagged_number_not_an_address.em` checks AN-78's value.
