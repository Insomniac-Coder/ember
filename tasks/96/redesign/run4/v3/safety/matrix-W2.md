# Safety matrix, writer W2: R4, R5, R6, R17

Agent W2 of safety validation (b). Rules R4 (parameters and calls), R5 (what a first line says), R6
(views a call gives) and R17 (inferred facts at a package's edge), with the refusals of section 3 and
the run-time checks of section 2 that belong to them. `V3` = `tasks/96/redesign/run4/v3/`; the tests
are in `V3/conformance/R4/`, `R5/`, `R6/`, `R17/` (121 files: 47 `accept_`, 70 `reject_`, 4 `run_`,
counted with `ls`). Nothing was compiled or run. Line numbers of `V3/rules.md` are given as `rules:N`.

Today's compiler, named in "enforced by" (paths under `compiler/`):
- parser: `ember_parser/src/decls.rs` (first lines, parameter modes; today's E0110), `body.rs` (calls);
- type checker: `ember_typeck/src/lib.rs` (today's E3023, E3027, E2100, E2103, E2140, E3013, E1010);
- borrow check (the MIR pass): `ember_analysis/src/borrows.rs` (today's E3020, E3021, E3022, E3060,
  E3062); moves: `ember_analysis/src/drops.rs` (E3040); fields set in `init`:
  `ember_analysis/src/definite_init.rs` (E2100);
- effects: `ember_analysis/src/effects.rs` (today's effect sets, `[EFF-1]`..`[EFF-8]`), the nearest
  existing pass for the `changes`/`reads` checks (E2105, E2113 are new codes for it);
- interface file: `ember_build/src/interface.rs` (today records `effects` per body, `[EFF-4]`);
- code generator: `ember_mir/src/lower.rs` (`lower_assert_disjoint`, line 1733; the index compare would
  be inserted here), `ember_codegen_c/src/lib.rs` (today's `restrict` kernels, `restrict_views`);
- runtime: `ember_rt`'s panic (the stop of the index compare and of `assert_disjoint`).

How a result is verified once built: `compile-fail` by the runner's expected `#$ error[CODE]: message`
on the refused line and the `#$ help:` line; `compile-pass`/`run-pass` by exit 0 and `#$ stdout:`;
`run-fail` by the `#$ panics:` start of the panic message. The rows marked "C check" also need the
generated C inspected (today's `#$ assert-c:` header), which no test writes yet because the model's C
spelling is not fixed.
