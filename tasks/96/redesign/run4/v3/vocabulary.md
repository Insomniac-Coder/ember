## 0. Terms used here

- **word**: anything a programmer writes to say something: a keyword (`owns`), an `@` attribute
  (`@noalloc`), or a library type or function that acts as a language word (`mem.take`).
- **the owner's test**: for every name a line declares, the word that says what it is (the owner's own
  thing, a copy, or handed over) and the word that says whether it may change it (brief).
- **view**: a value that points into something someone else owns and may not outlive it (`ref T`,
  `ref mut T`, `sharedref mut T`, `Span[T]`, `MutSpan[T]`, `StrView`, a plain parameter or loop name, a
  name opened with `exists as` or named by a kind test, `is T as`). A read-only view promises that what
  it reads does not change while it is used (R8 (g)).
- **change list**: what a function changes, as one list; a generic parameter written after `changes`
  stands for one, filled from the function given to the call (R12).
- **link**: a field or value that names an object it does not own alone (`weakref T`, `shares T`,
  `shares mut T`, `thread_shared T`, `sharedref mut T`).
- **`Copy` type**: a type whose values are copied bit for bit on assignment and whose copy is
  independent: numbers, `bool`, `ref T`, `Span`, `StrView`, structs of such. Class objects, `shares`
  values, `weakref` and `sharedref mut` links, `ref mut` views and `MutSpan`s are not `Copy`.
- **class object**: an object of a `class` type, in its own heap block, with one owner unless a line
  says `shares` (R1).
- **`this`**: inside a method, the object the method was called on (R5).
- **memory manager**: where a value's heap memory comes from: the built-in one, or one named with
  `using`, its kind in a type and its instance on the line that makes the value (R3).
- **kept callback**: a function value C keeps after the call that hands it over (`callback(retained)` or
  `callback(once)`), and runs during later foreign calls (R12).
- Verdicts in the table's last column: **keep**, **rename**, **merge**, **remove**, **new**, as in
  `RUN3/vocabulary.md` (not to be confused with the owner's verdicts, cited "verdict N").
