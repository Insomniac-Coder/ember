## 4. Technical points I settled

1. **The contract word `owned` stays** (`@ffi(param(widget, owned, one))`): verdict 91 and R16 spell it so;
   it is C's contract vocabulary beside `borrowed`, `retained`, `returns_owned`, not the removed mode
   `owned` (the vocabulary's `owned` row lists it as renamed; JOB comes first).
2. **C12's spelling: `@unsafe(export("name"))`, `@unsafe(export_table(...))`**, as Rust 2024's
   `#[unsafe(export_name = ...)]`; the attribute grammar already admits it. It covers an export with no
   name too (it takes the function's own name). Known names (`main`, the runtime prefix, the module
   protocol names, the C library's functions) stay E0104, today's code for `main`.
3. **C26:** only an overlay of another package needs `with (header_hash = "...")`; a package's own
   overlay is vouched for by its package (`[TIER-1]`). A mismatch or a missing hash is E5010.
4. **C25:** `unsafe import c` for C source and for `implementation = [...]`; E3100 without it.
5. **C07:** `@ffi(safe)` on a function-pointer typedef's overlay entry, only when every parameter and
   result is a scalar or `@layout(c)` value (E5002 otherwise).
6. **C16:** a `retained` pointer off a callback has no safe Ember type. A C++ parameter that keeps an
   object takes it over (`owner="foreign"`, `owned`), or gets `into_raw()`; E5060 now means "an
   `owner="ember"` object given to a C++ parameter that keeps it".
7. **C++ methods** list no receiver; whether one may change its object comes from `const` and
   `[FFI-40a]`'s body reading; an overlay line asserts "only reads" with `@ffi(const)`.
8. **C23:** a `thread_shared` count is one `fetch_add`, stopping when the old value is at or above
   2,147,483,647 (half range; 127 in the 8-bit test build); one-thread counts keep the exact compare.
9. **C31:** `[FFI-33a]`'s per-object creator check needed the old 24-byte header; no one-thread owner
   reaches C now (compile-time E7015/E7008), so the rule says so, and the remaining checks
   (`[FFI-33b]`, `[FFI-33c]`, the trampoline) run in every profile.
10. **C34 / ODR-162:** with the C++ header, only a `thread_shared` class value crosses an export,
    as a copyable handle on the atomic count; `[FFI-31b]` holds for everything else.
11. **E7012 for `creator` exports** too, as V5's E7012 row says; `creator` permits `threads(creator)`
    values.
12. **C29:** a toolchain that cannot probe is refused with a new code, **E9014** (free when checked:
    `grep -rlw` over `compiler`, `docs/spec-source`, `std`, `tests`, `tasks`: no file).
13. **XVIII.4** restated in views (positions, addresses) instead of loans; E3061 is folded into E3063
    (agent 07's table).
14. `CString.as_cstr()` keeps its method name; only the type `cstr` became `CStrView`.
