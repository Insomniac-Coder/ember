## 4. Technical points I settled

1. **A count's compare with its limit is `RuntimeCheck(Arithmetic)`** (`[EFF-9]`, `[EFF-16]`). It is an
   overflow check of a count, and it can stop the program; without a kind, `[EFF-16]`'s "free of
   `RuntimeCheck` has no panic the model knows of" would be false.
2. **`@no_alias_checks` forbids `check_disjoint` as well as `assert_disjoint`**, and no longer exempts
   `establishes_static_fact` sites (`[EFF-12]`): R16 and section 4's E4030 make `assert_disjoint` the
   refused case, and the vocabulary's row says "no `assert_disjoint`/`check_disjoint`". Today's
   exemption would contradict both.
3. **`[EFF-15]`'s proof list** drops `[EXC-3]`, `[EXC-8]` (no run-time exclusivity checks remain),
   `[RC-2]` (counts change only where a line says `shares`, `thread_shared` or `weakref`, so there is no
   implicit count to elide) and `[DSJ-1]` (no later check relies on it now), and adds the parent-link
   proof of Part VIII, the one proof that removes a run-time check (the header test of a parent-link
   read).
4. **`[EFF-2]`: effects of a call through a function value, `dyn` or `virtual` method are those of every
   function the program can put there**, as R12 and R5 say for changes; today's "the effects declared on
   its type, all if none" goes. A contract written on a function type (the attribute table allows
   `@deterministic` there) is checked where a function is stored. A foreign function pointer keeps
   "declared, or all".
5. **`[EFF-3]`: a foreign call's effect set stays its declared effects**; only what it changes through
   kept callbacks counts by R12 (`[EFF-26]`). No verdict adds the callbacks' effects (`Alloc`, ...) to the
   call's effect set, and doing so would refuse more `@noalloc` programs.
6. **E7015 for any one-thread value reachable from a value made `thread_shared`** (`[THR-1]`), at the
   line that makes it: R12 gives the plain-`fn()`-field case, and R15 says a one-thread owner reaching
   another thread is E7015; a `shares` field of a `thread_shared` object reaches every thread that holds
   the object.
7. **R15's "`shares`, `shares mut` and `weakref` only where the function stays on this thread"** is read
   as a `weakref` to a value that is not `thread_shared` (`[THR-17]`, `[THR-2]`), as R12 and E7015 say
   ("a `weakref` link of one") and as R10 point 2 needs (a `weakref` to a `thread_shared` object opened on
   another thread).
8. **E7007 covers a task reading a place another task or the parent changes** (`[THR-11]`), as the
   checker's X1 says R15 already does ("checked against the other tasks and the parent until the join");
   only E7007's one-line meaning omits the read.
9. **C03 for every thread, not only scoped tasks** (`[THR-2]`): making, ending or opening a `weakref` in
   any code that may run on another thread than the target's owner (a job, a `thread.spawn` function, a
   callback on another thread) is allowed only for a `thread_shared` target; the same race exists there
   (for example a one-owner object inside a `thread_shared` value).
10. **U3's E7012 is reported where the off-thread function is checked**, like any other change that
    function makes, not on the class.
11. **`Send` and `ThreadShared`** (`[THR-8]`, `[THR-9]`) are aligned with agent 03's marker table in
    `p04-types.md` (views `Send` on today's conditions; `ref mut T` not `ThreadShared`; `thread_shared T`
    `Send` when `T` is `Send` and `ThreadShared`). That a view never goes to an unscoped thread stays
    `[THR-2]`'s E7015, which is about lifetime, not the type.
12. **A `@parallel` loop walked by element writes nothing else but declared reductions**, and E7010's
    message gives lines that compile (R18) rather than today's fixed list of alternatives (`[PAR-2]`).
13. **A reduction of scoped tasks is not `Nondet`** (`[DET-2]`, `[THR-21]`): it is combined in spawn
    order, the same on every run (verdict 92's "the same answer on every run").
14. **`[COST-6]` repeats `[PRF-4]`'s stop texts**, word for word, because the crosswalk makes the cost
    model the first home of section 2; the lead may keep one and cite it from the other.
