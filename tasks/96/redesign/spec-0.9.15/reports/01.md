1. **Markers.** New rules say `*(new in 0.9.15)*`, changed ones add `*(changed in 0.9.15)*`, as agents

3. **C23's limit**: a `thread_shared` count stops when the value before the atomic add is 2,147,483,647

   the stop texts name that limit. One-thread counts keep the exact compare and the 4,294,967,295 text.
   Verdict 96's 8-bit tests are unchanged where they use one-thread objects.
4. **C04's code**: `E3016` (today's "`self` escapes its own drop"), which agent 07 widened the same way;
   no run-time check replaces `[OBJ-5]`'s old panic.

   in the program may name an object, and every shared value of a type a `weakref` may name; the
   family, so a base class's layout stays a prefix of a derived class's.
6. **A `shares` value of a struct type** gets the same header as a class object (`[RC-1]`, VIII.1); V5
   says only that it lives in its own block and is counted.
7. **`from` names one parameter or one field** (R6); `@borrows(p, q)`'s several names go. A
   multi-region result under `from` points only into what `from` names (`[LT-23]`, `E3062`), since
   `E3065` is retired.
8. **`[RC-2]`'s guaranteed elisions** restated as "no count where no owner is made": views never count
   (except `[RC-5]` point 2), a hand-over moves.
9. **Part numbering**: `Span`/`MutSpan` kept at §VII.7, which `p04` cites; §VIII.3 kept as the section on
   changes through several names, which `p06` and `p18` cite.
10. **`get_pair_mut`** stays as a library function (it checks and returns `None`; the program asks for
