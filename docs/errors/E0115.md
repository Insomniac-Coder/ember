# E0115 — `Some(...)` in an `if` or `while` header

```ember,fails
fn main():
    best: Option[int] = Some(5)
    if Some(b) = best:
        println(b)
```

```text
error[E0115]: an `Option` is opened with `exists as`, not `Some(...)` in a header
  = help: write `best exists as b`
```

## Why

`if best exists as b:` says what the line checks, that `best` holds something, and `as b` names
it, as `import x as y` does. `Some(...)` makes a value (`best = Some(5)`) and names a `match`
branch (`Some(b):`), never a header, so each form has one place. A header that tests a value
inside the `Option` is a comparison (`if best == Some(5):`) or a `match`.

## The fix

```ember,fixed
fn main():
    best: Option[int] = Some(5)
    if best exists as b:
        println(b)
```
