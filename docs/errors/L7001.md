# L7001 — lock held across a call that may block

```ember,fails
import std.sync
import std.time

fn main():
    m = sync.Mutex(0)
    with g = m.lock():
        g += 1
        time.sleep(time.Duration.from_millis(1))
    println("done")
```

```text
warning[L7001]: the lock `g` guards is held across a call that may block
```

## Why

A call that may block (a sleep, a wait on another thread, a channel's `recv`, another lock) can take
any length of time, and while it waits every thread that wants the lock waits too. If the call waits
for one of those threads, neither ever moves: a deadlock.

## The fix

Release the lock before the call: end the `with` block first.

```ember,fixed
import std.sync
import std.time

fn main():
    m = sync.Mutex(0)
    with g = m.lock():
        g += 1
    time.sleep(time.Duration.from_millis(1))
    println("done")
```
