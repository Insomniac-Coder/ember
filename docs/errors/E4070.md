# E4070 — a `@deterministic` function reaches a nondeterministic operation

```ember,fails
fn wave(x: f64) -> f64:
    return x.sin()

@deterministic
fn angle(x: f64) -> f64:
    return wave(x) * 2.0

fn main():
    println(angle(0.0))
```

```text
error[E4070]: `@deterministic` function `angle` reaches a nondeterministic operation
  = note: angle -> wave -> a transcendental function from the platform library
```

## Why

Lock-step networking, replays and golden-image tests need two runs of a program to compute the
same bits, on every machine. The platform library's `sin` gives different last bits on different
C libraries, so a `@deterministic` function may not reach it.

## The fix

```ember,fixed
fn wave(x: f64) -> f64:
    return x * 2.0

@deterministic
fn angle(x: f64) -> f64:
    return wave(x) * 2.0

fn main():
    println(angle(0.0))
```

Use `std.math.det`'s functions, which give the same bits on every target (`[DET-4]`).
