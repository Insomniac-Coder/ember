# E0116 — a name with no word after a name with one

```ember,fails
fn run(f: fn(ref mut int, int)):
    n = 1
    f(ref mut n, 2)
    println(n)

fn main():
    run(fn(ref mut x, y): x += y)
```

```text
error[E0116]: `ref mut` here belongs to `x` only; say what `y` is
  = help: write `ref y` to read it, or `ref mut y` to treat it as `x` is treated
```

## Why

In a list of names declared without types of their own (a lambda's parameters, a loop's names, a
pattern's names, the names after `exists as`), each word belongs to the one name after it. A name
with no word after a name with one could be read as sharing that word, so the list says what each
name is.

## The fix

```ember,fixed
fn run(f: fn(ref mut int, int)):
    n = 1
    f(ref mut n, 2)
    println(n)

fn main():
    run(fn(ref mut x, ref y): x += y)
```
