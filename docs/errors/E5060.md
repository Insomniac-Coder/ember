# E5060 — an object C++ keeps is passed without a `Retained` token

```cpp,file=layer.hpp
#pragma once

class Layer {
public:
    Layer() noexcept {}
    virtual ~Layer() {}
    virtual int on_update(int step) noexcept { return step; }
};

inline Layer* kept = nullptr;
inline void keep(Layer* layer) noexcept { kept = layer; }
inline int update_kept() noexcept { return kept != nullptr ? kept->on_update(2) : -1; }
```

```ember,file=layer_overlay.em
unsafe overlay cpp "layer.hpp":  # SAFETY(ffi): each entry matches its declaration in the header
    @ffi(trampoline, virtuals=["on_update"])
    type Layer
    fn keep(layer: retained)
    fn update_kept()
```

```ember,fails
import cpp "layer.hpp" with (overlay = "layer_overlay.em")

class Doubled(cpp.Layer):
    override fn on_update(self, step: i32) -> i32:
        return step * 2

fn main():
    cpp.keep(Doubled())
```

```text
error[E5060]: C++ keeps this object, and nothing here holds the `Retained` token that keeps it alive for C++
 --> page.em:8:14
  |
8 |     cpp.keep(Doubled())
  |              ^^^^^^^^^
  |
  = help: pin it and keep the token as long as C++ needs the object: `token = Retained.pin(…)`, then pass `token` (a `Retained[Layer]`)
  = note: a parameter that keeps the object takes the token the program holds (ODR-156) [FFI-39c]
```

## Why

`keep` stores the pointer it is given. An Ember object lives while something holds a count of it, and
C++ holds none: the object passed here would be destroyed at the end of the statement, and the next
C++ call through the stored pointer would reach a deleted object. A `Retained` token is the count C++
needs, and the program decides how long it lives — as long as C++ may use the object. Passing the
object to a parameter that only borrows it for the call needs no token: the caller's handle keeps it
alive until the call returns.

## The fix

Pin the object, keep the token as long as C++ needs the object, and pass the token. A token of a
class is a token of its C++ base.

```ember,fixed
from std.ffi import Retained

import cpp "layer.hpp" with (overlay = "layer_overlay.em")

class Doubled(cpp.Layer):
    override fn on_update(self, step: i32) -> i32:
        return step * 2

fn main():
    token = Retained.pin(Doubled())
    cpp.keep(token)
    println(cpp.update_kept())
```
