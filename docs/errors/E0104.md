# E0104 — an attribute or construct not admitted here

```ember,fails
@frobnicate
fn main():
    println(1)
```

```text
error[E0104]: `@frobnicate` is not an attribute
```

## Why

An attribute changes what the compiler does with a declaration, so an unknown one is never accepted and ignored: that would let a misspelling silently drop a requirement (`[ATT-1]`, `[PHIL-12]`).

## The fix

Remove the attribute, or write one from the attribute table of `[ATT-1]`:

```ember,fixed
fn main():
    println(1)
```
