# E2230 — a name assigned in every branch at different types

```ember,fails
fn main():
    n = 1
    if n > 0:
        v = 1
    else:
        v = "one"
    println(v)
```

```text
error[E2230]: `v` is assigned in every branch, but at different types
```

## Why

A name that every branch of an `if`/`else` (or an exhaustive `match`) declares
is declared after the branch, as Python lets you write (`[CTL-10]`). After the
branch there is one `v`, so it has one type; which branch ran is not known when
the program is compiled, so a `v` that is an `int` on one path and a `str` on
the other has no type to be.

## The fix

Give the name one type in every branch — or, when the branches really compute
different things, give them different names:

```ember,fixed
fn main():
    n = 1
    if n > 0:
        v = "1"
    else:
        v = "one"
    println(v)
```
