# E9034 — invalid `max_instantiations` value

```toml
[build]
max_instantiations = 0
```

```ember,fails
fn main():
    println("hello")
```

```text
error[E9034]: `max_instantiations = 0` is not a positive whole number
```

## Why

`[build] max_instantiations` is the most instances one of the package's generics may have before
`W2220` warns. A ceiling of zero, a negative number or a word sets no ceiling anyone could meet or
read, so the manifest says nothing until it is a positive whole number.

## The fix

Write the most instances one generic may have, or leave the key out for no ceiling.

```toml
[build]
max_instantiations = 64
```

```ember,fixed
fn main():
    println("hello")
```
