# E1050 — a field is read-only outside its module

```ember,file=shapes.em
pub struct Point:
    pub(read) x: int

    pub fn move_to(x: int):
        this.x = x

pub fn make() -> Point:
    return Point(1)
```

```ember,fails
import shapes

fn main():
    p = shapes.make()
    p.x = 5
    println(p.x)
```

```text
error[E1050]: `shapes.Point.x` is read-only outside its module
  = help: `shapes.Point` declares `x` as `pub(read)`: anyone may read it, and only `shapes.Point`'s own module may write it
  = note: a method on the declaring type is the way to change it from outside [MOD-7]
```

## Why

A `pub(read)` field lets every user see a value while only the declaring module changes it, so the module can keep a promise about it (a length that matches a buffer, a count that matches a list) that a stray write from elsewhere would break (`[MOD-7]`). Construction is a write too, so a `pub(read)` field makes the memberwise constructor private to its module: outside code gets a value from a function the module offers, as `make` does here.

## The fix

Change it through a function or method the declaring module provides:

```ember,file=shapes.em
pub struct Point:
    pub(read) x: int

    pub fn move_to(x: int):
        this.x = x

pub fn make() -> Point:
    return Point(1)
```

```ember,fixed
import shapes

fn main():
    p = shapes.make()
    p.move_to(5)
    println(p.x)
```
