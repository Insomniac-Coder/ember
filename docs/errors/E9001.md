# E9001 — invalid manifest

```toml
[package]
name = "page"
version = "0.1.0"
bakcend = "c"
```

```ember,fails
fn main():
    println("hello")
```

```text
error[E9001]: unknown key `bakcend` in `[package]`
 --> ember.toml:4:1
  |
4 | bakcend = "c"
  | ^^^^^^^^^^^^^
  |
  = help: `[package]` accepts `name`, `version`, `language`, `kind`, `layers`, `edition_lints`
```

## Why

The manifest says how a package is built, and a key the compiler does not know would be silently ignored: the
build would go on as if the author had not written it, with a setting that did nothing. An invalid manifest,
including one with an unknown key, is therefore refused, naming the key and the keys that section accepts
(`[MAN-1]`).

## The fix

Spell the key as the section accepts it, or remove it:
```toml
[package]
name = "page"
version = "0.1.0"
```

```ember,fixed
fn main():
    println("hello")
```
