# L1002 — assignment declares a new binding

```ember,fails
fn main():
    total = 0
    for i in 0..3:
        totl = total + i
    println(total)
```

```text
warning[L1002]: `totl` declares a new binding; `total` is already in scope
 --> page.em:4:9
  |
4 |         totl = total + i
  |         ^^^^^^^^^^^^^^^^ did you mean to assign to `total`?
  |
  = help: write `total = â€¦`
  = note: `x = e` declares when `x` is not in scope and assigns when it is (GRM-4)
```

## Why

`totl = total + i` looks like a change to `total`, but in Ember an assignment to an unknown name declares a new
one. A new name that is never read and lies within distance 2 of a mutable binding in scope is usually a typo
(`[LNT-2]`), and it is an error under `edition_lints = "strict"`.

## The fix

Write the name that was meant:

```ember,fixed
fn main():
    total = 0
    for i in 0..3:
        total = total + i
    println(total)
```
