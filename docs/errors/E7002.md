# E7002 — a static type is not `Sync`

```ember,fails
static HITS: Cell[int] = Cell(0)

fn main():
    HITS.set(HITS.get() + 1)
```

```text
error[E7002]: static type `Cell[int]` is not Sync
```

## Why

Every thread can read an Ember `static` without writing `unsafe`. So a static must hold a value
that several threads can use at the same moment without corrupting it: a `Sync` value. A `Cell`
is not one. Two threads adding to `HITS` at once could each read 5 and both write 6, and lose an
addition.

The same applies to a foreign static marked `@ffi(immutable)`, because that marking lets code read
it without `unsafe`. A foreign static without that marking is read and written only inside
`unsafe`, where the programmer answers for its use across threads, so it may hold any value C lays
out, a pointer included (Part XVI's import table).

## The fix

Hold a `Sync` type that coordinates the threads, such as an atomic counter or a `Mutex`:

```ember,fixed
from std.sync import Mutex

static HITS: Mutex[int] = Mutex(0)

fn main():
    with h = HITS.lock():
        h += 1
```
