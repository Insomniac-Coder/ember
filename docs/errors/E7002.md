# E7002 — a static type is not `Sync`

```ember,fails
unsafe extern "C":
    static foreign_pointer: *i32

fn main():
    pass
```

```text
error[E7002]: foreign static type `*i32` is not Sync
```

## Why

A static is shared across threads. Its value type must be `Sync`, even when a
foreign declaration requires `unsafe` to access it. Raw pointers do not meet
that requirement.

## The fix

Declare a `Sync` C-compatible value, or expose the pointer through a foreign
function whose contract describes access to it:

```ember,fixed
unsafe extern "C":
    static foreign_count: i32

fn main():
    unsafe:
        println(foreign_count)
```
