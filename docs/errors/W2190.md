# W2190 — an unused `Result`

```ember,fails
fn parse(s: str) -> Result[int, str]:
    return Ok(s.len())

fn main():
    parse("x")
```

```text
warning[W2190]: unused `Result`, which may be an error
```

## Why

A `Result` carries either a value or an error. Dropping one in an expression statement discards
the error with it, so a failure goes unnoticed. `Result` is `@must_use`; under `-D warnings` this
is an error.

## The fix

Handle it, or drop it on purpose with `_ = …`:

```ember,fixed
fn parse(s: str) -> Result[int, str]:
    return Ok(s.len())

fn main():
    match parse("x"):
        Ok(n):
            println(n)
        Err(e):
            println(e)
    _ = parse("y")
```

A `Result` is used when it is bound, returned, passed, matched, or has `?` or a method applied.
