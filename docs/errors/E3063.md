# E3063 — a view kept where it would outlive what it points into

```ember,fails
fn fill(ref mut out: StrView):
    buf = String.from("temporary")
    out = buf.as_str()

fn main():
    name = "ann"
    fill(ref mut name)
    println(name)
```

```text
error[E3063]: a view of `buf` is stored in `out`, which the caller owns, so it would outlive `buf`
 --> page.em:3:11
  |
3 |     out = buf.as_str()
  |           ^^^ stored here
  |
  = help: return the view instead, or store an owned copy (`String` for `StrView`)
  = note: a `ref mut` parameter is the caller's place: a `StrView` stored in it must outlive the call, and `buf` ends with it (TYP-15, FN-1)
```

## Why

A view, or a value holding views, kept or returned where it would outlive what it points into is `E3063`
(`[TYP-15]`): whatever holds a view lives no longer than what the view points into. `out` is the caller's place,
which outlives the call, while `buf` ends when `fill` returns, so the caller would be left with a view of memory
that was freed.

## The fix

Store a value the caller's place can own instead of a view of a local:

```ember,fixed
fn fill(ref mut out: String):
    out = String.from("temporary")

fn main():
    name = String.from("ann")
    fill(ref mut name)
    println(name)
```
