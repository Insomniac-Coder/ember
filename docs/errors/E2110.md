# E2110 — overriding a non-virtual method

```ember,fails
open class Base:
    fn tick(self):
        pass

class Child(Base):
    override fn tick(self):
        pass

fn main():
    println(1)
```

```text
error[E2110]: override of a method that is not virtual
```

## Why

An `override` declaration promises that the derived method participates in the
base class's virtual dispatch contract. A non-virtual base method has no such
contract, so accepting the declaration would make the source promise stronger
than the dispatch model the program actually has.

## The fix

Declare the base method `virtual` when it is intended to be overridden. The
derived declaration can then use `override` and the compiler can verify the
relationship across the class hierarchy.

```ember,fixed
open class Base:
    virtual fn tick(self):
        pass

class Child(Base):
    override fn tick(self):
        pass

fn main():
    println(1)
```
