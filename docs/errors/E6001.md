# E6001 — compile-time evaluation that cannot end

```ember,fails
const WIDTH: i32 = HEIGHT * 2
const HEIGHT: i32 = WIDTH // 2

fn main():
    println(WIDTH)
```

```text
error[E6001]: the value of `WIDTH` depends on itself
```

## Why

Constants are worked out while the program compiles, each when it is first
needed, so they may name one another in any order. A constant whose value
needs its own value has no first step: working it out would never end. The
compiler reports the cycle where it closes instead. Compile-time evaluation
that runs past its step or memory limit is the same error, for the same
reason: a build must finish.

## The fix

Give one of them a value of its own:

```ember,fixed
const HEIGHT: i32 = 540
const WIDTH: i32 = HEIGHT * 2

fn main():
    println(WIDTH)
```
