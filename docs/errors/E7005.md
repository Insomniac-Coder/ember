# E7005 — a value shared with a task is not `Sync`

```ember,fails
import std.thread

fn main():
    count = RefCell(0)
    with scope = thread.scope():
        scope.spawn(fn() => count.borrow().clone())
```

```text
error[E7005]: the task borrows `count`, a `RefCell[i64]`, which is not Sync
```

## Why

A scoped task runs on another thread while the block goes on, and a shared borrow lets both
threads use the place at once. A type is `Sync` when that is safe; a `RefCell` counts its borrows
in plain memory, so two threads borrowing it at once could corrupt the count. (A `Copy` value such
as a `Cell[int]` is copied into the task instead, and shares nothing.)

## The fix

Hold the value in a type made for sharing, such as an `Atomic`:

```ember,fixed
import std.thread
from std.sync import Atomic

fn main():
    count = Atomic(0)
    with scope = thread.scope():
        scope.spawn(fn() => count.fetch_add(1))
    println(count.load())
```
