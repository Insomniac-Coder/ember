# E9012 — reserved

`E9012` is reserved and never emitted. The number stays in the registry so that it is not given to another
diagnostic (`[DIA-6a]`: codes are never reused).

## Why

The specification's registry lists it among the retired codes with the one word "reserved": no rule
defines a diagnostic for it.

## See also

* `[DIA-6a]` — the registry is exhaustive in both directions, and a code is never reused.
