# E2160 — control flow cannot leave a `defer` block

```ember,fails
fn leaves() -> int:
    defer:
        return 1
    return 0

fn main():
    println(leaves())
```

```text
error[E2160]: control flow cannot leave a `defer` block
 --> page.em:3:9
  |
3 |         return 1
  |         ^^^^^^^^
  |
```

## Why

A `defer` block runs while its enclosing block is exiting, last registered first (`[CTL-7]`). A `return`,
`break`, `continue` or `yield` inside it would start a second exit from the middle of the first one, so
the blocks still to run and the locals still to be dropped would have no defined order. Control flow
therefore cannot leave a `defer` block.

## The fix

Do the `return` (or `break`, `continue`) outside the `defer` block, after the work it guards:

```ember,fixed
fn leaves() -> int:
    defer:
        println("done")
    return 0

fn main():
    println(leaves())
```
