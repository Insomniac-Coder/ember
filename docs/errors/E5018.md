# E5018 — a `VaList` is constructed

```ember,fails
from std.ffi import VaList

fn main():
    arguments = VaList()
```

```text
error[E5018]: a `VaList` is never constructed
```

## Why

A C `va_list` is the variadic call's own record of where its further arguments are: the variadic
function makes it with `va_start` over its own arguments, and it means something only during that
call. Ember has no arguments to describe, so a `VaList` it made would describe nothing, and the C
function given it would read whatever memory it pointed at. Ember only receives one, as a parameter
of a function C calls, and passes it on, once, to a C function that reads it (`vsnprintf`).

## The fix

Take the `VaList` C hands over and pass it on:

```ember,fixed
from std.ffi import VaList, c_char, c_int

unsafe extern "C":  # SAFETY(ffi): each declaration below matches its C definition
    @safety("`buffer` holds `size` bytes, and `arguments` are what `format` reads")
    unsafe fn vsnprintf(buffer: *mut c_char, size: usize, format: *c_char, owned arguments: VaList) -> c_int

extern "C" fn sink(context: *mut void, format: *c_char, owned arguments: VaList):
    unsafe:  # SAFETY(ffi): a null buffer of size 0 only counts the bytes
        println(vsnprintf(null[*mut c_char](), 0, format, arguments))

fn main():
    pass
```
