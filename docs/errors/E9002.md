# E9002 — no C compiler found, or it failed

The C toolchain a build needs is missing or refused its input. For a program that imports a C
header, that includes libclang, which parses the header, and the header itself.

```c,file=present.h
static inline int present_answer(void) { return 42; }
```

```ember,fails
import c "absent.h"

fn main():
    pass
```

```text
error[E9002]: cannot import `absent.h`
 --> page.em:1:1
  |
1 | import c "absent.h"
  | ^^^^^^^^^^^^^^^^^^^
  |
  = note: 'absent.h' file not found
  = note: `import c` parses the header with libclang [FFI-6]
```

When libclang itself is missing the note names what to install: LLVM (`winget install LLVM.LLVM` on
Windows, `apt install libclang-dev` on Debian and Ubuntu), or `LIBCLANG_PATH` set to the folder that
holds it.

## Why

Ember compiles to C and reads C headers with Clang. Without the tool that does that, or with a
header it cannot find or parse, there is no correct program to build, and guessing at the
declarations would make one whose calls do not match the library it links. The diagnostic gives the
C tool's own words, so the fix is the one the C tool asks for.

## The fix

Import a header the search finds — beside the importing file, under an `include_paths` entry, or a
system header:

```ember,fixed
import c "present.h"

fn main():
    unsafe:  # SAFETY(ffi): a call with no arguments
        println(c.present_answer())
```
