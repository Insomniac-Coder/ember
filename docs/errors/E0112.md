## Why

Every expression, block and type the compiler reads is a tree, and each pass of
the compiler walks it one level at a time. A tree deeper than the compiler can
hold would end the compiler with no explanation, so it states a limit and
reports passing it: 1,024 levels here, where the specification asks every
compiler for at least 256. An operator chain counts as deep as it is long —
`1 + 1 + … + 1` is `(((1 + 1) + 1) + …)` — as does a chain of method calls. The
error is reported once, where the limit is passed.

Programs written by hand rarely come near; generated code can.
