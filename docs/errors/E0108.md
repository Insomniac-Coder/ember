# E0108 — an attribute not permitted on a statement

```ember,fails
fn main():
    c = 1
    @simd
    c = c + 1
    println(c)
```

```text
error[E0108]: `@simd` must precede a compound statement
```

## Why

A statement attribute describes the loop or branch it stands above, so it attaches to the next compound statement and never to a simple one; `@simd`, `@parallel` and `@unroll` need a `for` (`[ATT-3]`, `[GRM-20]`). Attached to `c = c + 1` it would describe nothing.

## The fix

Remove the attribute, or attach it to the `for` it describes:

```ember,fixed
fn main():
    c = 1
    c = c + 1
    println(c)
```
