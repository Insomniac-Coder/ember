# E1052 — an item, field or constructor that is not visible here

```ember,fails
from std.core import option_map

fn main():
    println(option_map(Some(2), fn(x) => x * 10))
```

```text
error[E1052]: `option_map` is private to `std.core`
```

## Why

An item is private to its module unless it is marked `pub` (`[MOD-2]`), and a
field likewise; a memberwise constructor is `pub` only when every field is,
because constructing writes them all. What a module keeps private is free to
change: it is not part of what the module promises to other modules. Reaching
it from outside — by name, through the module, or by reading a field — would
make every such change a break, so each of those uses is refused, and the
diagnostic names where the item is declared and how visible it is.

## The fix

Use what the module exports. Here, `Option.map` is the public way to what the
private helper does:

```ember,fixed
fn main():
    println(Some(2).map(fn(x) => x * 10))
```
