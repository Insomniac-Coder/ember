# W2192 — use of a deprecated item

```ember,file=shapes.em
@deprecated(since="0.9", note="use `area_of` instead")
pub fn area(w: int, h: int) -> int:
    return w * h

pub fn area_of(w: int, h: int) -> int:
    return w * h
```

```ember,fails
import shapes

fn main():
    println(shapes.area(2, 3))
```

```text
warning[W2192]: `shapes.area` is deprecated since 0.9: use `area_of` instead
```

## Why

A library cannot take an item away from the programs that use it without breaking them, and it
should not keep an item forever because they might. `@deprecated(since, note)` is the middle
step: the item still works, every use of it from another module says since when it has been on
its way out and what to use instead, and it is removed no earlier than the next major version.
Its own module may keep using it while its callers move.

## The fix

Use what the note names:

```ember,fixed
import shapes

fn main():
    println(shapes.area_of(2, 3))
```
