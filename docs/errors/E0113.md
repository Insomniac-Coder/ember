# E0113 — `mut` alone on a name

```ember,fails
fn bump(mut n: int):
    n += 1

fn main():
    k = 1
    bump(ref mut k)
    println(k)
```

```text
error[E0113]: `mut` alone is no word for a parameter: one the function may change is `ref mut`
  = help: write `fn bump(ref mut n: int):`
```

## Why

A parameter's word says what the function is given: none (or `ref`) a read-only view of the
caller's value, `ref mut` the caller's place itself, which the function may change, `owns` the value
handed over. `mut` alone says the name can be changed but not whose value that changes, so it is no
word. On a name a pattern declares the same holds: `ref mut v` changes the part matched, and
`copy of v` is a copy of your own that you may change.

## The fix

```ember,fixed
fn bump(ref mut n: int):
    n += 1

fn main():
    k = 1
    bump(ref mut k)
    println(k)
```
