# E2200 — type has infinite size

```ember,fails
gen fn walk(n: int) -> Generator[int]:
    if n > 0:
        for x in walk(n - 1):
            yield x
    yield n

fn main():
    for x in walk(2):
        println(x)
```

```text
error[E2200]: this generator holds its own frame across a `yield`, which gives the frame no size
 = note: a frame's size is fixed when it is compiled [CORO-5]; a recursive generator holds the inner one in a `Box[dyn Iterator[Item = …]]`
```

## Why

A value's size must be known when the program is compiled (Part XVIII §4.4): a
value holding another of its own type would need room for a copy of itself,
inside which is another copy, without end. A generator's frame is such a value
(`[CORO-5]`): it holds every local that lives across a `yield`, and a recursive
generator that iterates itself holds another frame of its own type there.

## The fix

Keep the inner generator somewhere of a fixed size, a box, or write the walk as
a loop:

```ember,fixed
gen fn walk(n: int) -> Generator[int]:
    for i in 0..=n:
        yield i

fn main():
    for x in walk(2):
        println(x)
```
