# E3012 — retired: a field of a class object handed out on its own

`E3012` is no longer emitted. It refused handing a field of a class object out on its own (`x = node.name`), since every handle to the object could still reach the field and would see the hole.

Since 0.9.20 it is folded into `E3013`, which refuses every hand-over out of a place that does not own the value alone: "`a` is a `Node` object, which other names may reach, so `a.name` cannot be taken out and leave a hole; take it and leave a value in its place: `mem.take(ref mut a.name)`".
