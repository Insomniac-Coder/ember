# W2091 — unreachable match arm

```ember,fails
fn main():
    word = "a"
    match word:
        "a":
            println(1)
        "a":
            println(2)
        _:
            println(3)
```

```text
warning[W2091]: this arm can never match
 --> page.em:6:9
  |
6 |         "a":
  |         ^^^^ the arms above already cover every value this matches
  |
```

## Why

A `match` tests its arms from the top and the first that matches runs (`[CTL-5]`), so an arm that an earlier arm
always covers can never run. It is usually a copy-and-paste slip, and the compiler warns that the arm is dead.

## The fix

Remove the arm, or change its pattern to the case that was meant:

```ember,fixed
fn main():
    word = "a"
    match word:
        "a":
            println(1)
        "b":
            println(2)
        _:
            println(3)
```
