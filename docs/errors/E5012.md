# E5012 — pointer contract has no count

```ember,fails
unsafe extern "C":
    @ffi(param(data, borrowed))
    fn inspect(data: *u8, dataLen: usize) -> i32

fn main():
    pass
```

```text
error[E5012]: pointer contract for `data` has no count
 = help: choose one, count(n), nul_terminated, fixed(N), or inout_count(p)
 = note: possible length parameter: dataLen
```

## Why

Ownership alone does not say how much memory a foreign function may read or
write through a pointer. Without a count, callers and the compiler cannot
establish the bounds of that access. An unsigned or length-named sibling is
reported as a clue, not silently assumed to be the count.

## The fix

State the count that the C function actually uses. This example contracts a
single element; a function that uses `dataLen` needs `count(dataLen)` when
that contract form is available.

```ember,fixed
unsafe extern "C":
    @ffi(param(data, borrowed, one))
    fn inspect(data: *u8) -> i32

fn main():
    pass
```
