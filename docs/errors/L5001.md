# L5001 — `unsafe extern` declaration with no contract

```ember,fails
unsafe extern "C":  # SAFETY(ffi): each declaration below matches its C definition
    fn strlen(text: *u8) -> usize

fn main():
    println("declared")
```

```text
warning[L5001]: `strlen` is an `unsafe extern` declaration with no contract
```

## Why

C's declaration says what a function's pointers are, not what it does with them: whether it reads
one value or a run of them, keeps the pointer, frees it, or accepts null. A declaration that states
none of it leaves every call `unsafe` and every caller to work out the rules again by reading C's
documentation. The contract writes them down once, where the compiler checks every call against
them.

## The fix

State what C does with each pointer in `@ffi(…)`, and mark the declaration `safe` when its contract
makes every call safe.

```ember,fixed
unsafe extern "C":  # SAFETY(ffi): each declaration below matches its C definition
    @ffi(param(text, borrowed, nul_terminated))
    safe fn strlen(text: cstr) -> usize

fn main():
    println(strlen(c"declared"))
```
