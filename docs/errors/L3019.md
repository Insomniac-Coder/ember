# L3019 — retired: an object deinitialised before its last owner ends

`L3019` is no longer emitted. It warned that an object could be deinitialised before the last place that
names it is used.

An object is deinitialised when its last owner ends, as the source says, and never earlier (`[RC-3]`,
ODR-063), so there is nothing left to warn about and the number is not reused.

## Why

Deinitialisation that moves earlier than the last syntactic use would make a program's output depend on an
optimisation. The rule fixes the moment instead: the end of the owner's scope, or the hand-over that ends it.
