# E2036 — a pattern that always matches

```ember,fails
fn main():
    x = 1
    if x = 5:
        println("five")
```

```text
error[E2036]: this pattern always matches
  = help: did you mean `x == 5`?
  = note: to declare `x`, write `x = 5` on the line before
```

## Why

An `if` or `while` header with a pattern asks "does this value have this shape?" (`[GRM-19]`), and a question whose answer is always yes is not a question. The usual cause is `=` written for `==`: `if x = 5:` would bind a new `x` and always run, which is never what the programmer meant, so the compiler refuses it and offers the comparison.

## The fix

Compare with `==`:

```ember,fixed
fn main():
    x = 1
    if x == 5:
        println("five")
```
