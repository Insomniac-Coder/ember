# E2211 — a constant outside the target's range

```ember,fails
type Roughness = f32 in 0.0 ..= 1.0

fn main():
    roughness: Roughness = 1.4
    print(1)
```

```text
error[E2211]: 1.4 is outside `Roughness`

    roughness: Roughness = 1.4
                           ^^^ `Roughness` holds 0.0 ..= 1.0

  = help: clamp it, or take the fallible form: `Roughness.checked(1.4)`
```

## Why

The compiler knows this value at compile time and knows the range, so there are
only two honest outcomes: accept it, or say now that it will never be in range.
Emitting a runtime check for a constant would be paying at every execution for
a question already answered, and letting it through would make `[RNG-9]`'s
invariant false — "a value of a range type whose representation does not lie in
the declared range is **invalid**; producing one is undefined behaviour".

That invariant is what earns the feature its keep. `[RNG-4]` may *assume* a
range value is in range, which is what lets it discharge an overflow check or a
bounds check downstream. An out-of-range value is not merely a wrong number: by
`[RNG-7]` a range type is a niche, so it is a bit pattern that is neither a
payload nor a discriminant.

## The fix

Write a constant that is in range, or construct through one of `[RNG-10]`'s
routes. `T.clamped(v)` is **total** — no failure mode, no `Panic`, no
`RuntimeCheck` — and is the right answer when a value outside the range should
be pulled to the edge. `T.checked(v)` returns a `Result` and is the right
answer when the difference matters.

```ember,fixed
type Roughness = f32 in 0.0 ..= 1.0

fn main():
    a: Roughness = 1.0              # in range: no check is emitted
    b = Roughness.clamped(1.4)      # total: 1.4 becomes 1.0
    match Roughness.checked(1.4):   # fallible: this is the `Err` arm
        Ok(v) => print(1)
        Err(e) => print(0)
    x: f32 = a
    y: f32 = b
    print(x)
    print(y)
```

## See also

* `[RNG-3]`, `[RNG-3a]` — `checked` and `clamped`.
* `[RNG-10]` — the closed construction set, and `E2215` when something outside
  it is tried.
* `L2003` — a lint for `checked` where `clamped` would do, because a `Result`
  the programmer immediately unwraps is a panic path that need not exist.
