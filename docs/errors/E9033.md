# E9033 — `reload` is forbidden in `shipping`

The error comes from how the package is built, not from its source: the program below is valid,
and checking it in the default `debug` profile is clean. Built for shipping, it is refused:

```toml
[build]
reload = "all"
```

```ember,fails,toolchain
fn main():
    println("hello")
```

```text
$ ember build --profile shipping main.em
error[E9033]: this package's manifest asks for hot reload, which `shipping` does not admit
```

## Why

A reloadable build reaches its functions through thunks, keeps a reload manifest in its image,
links a shared runtime and gives every object a larger header. Each of these costs speed and size
that a release to users should not pay, and each is a way into the running program that a shipped
one should not have. Hot reload is a mode of the `debug` and `release` profiles, never of
`shipping`.

## The fix

Build for shipping from a manifest that does not ask for reload (or with `reload = "none"`), and
keep `reload` for the profiles you develop in.

```toml
[build]
reload = "none"
```

```ember,fixed
fn main():
    println("hello")
```
