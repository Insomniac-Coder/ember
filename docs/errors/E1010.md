# E1010 — a name that is not in scope

```ember,fails
fn main():
    println(total)
```

```text
error[E1010]: cannot find `total` in this scope
```

## Why

A name the program has not declared, or declared in a block that has ended, cannot stand for anything. Ember does not create a name by use inside an expression, and a misspelling is reported where it is written rather than becoming a new variable (`[MOD-3]`).

## The fix

Declare the name before it is used, or correct the spelling:

```ember,fixed
fn main():
    total = 3
    println(total)
```
