# E1031 — a name two glob imports bind is used

```ember,fails
from std.math import *
from std.math.det import *

fn main():
    println(sqrt(9.0))
```

```text
error[E1031]: `sqrt` is bound by two glob imports, from `std.math` and `std.math.det`
```

## Why

`from m import *` binds every `pub` item of `m` (`[MOD-8]`). When two glob
imports bring in different items of one name, nothing in the program says which
one it means, and picking either by import order would let reordering two lines
change what a call does. The name is therefore bound to neither; the program is
rejected only if it uses it, so a glob that happens to overlap another in a name
the program never writes costs nothing.

## The fix

Import the one you mean by name; an explicit import shadows a glob:

```ember,fixed
from std.math import *
from std.math.det import *
from std.math import sqrt

fn main():
    println(sqrt(9.0))
```

Or name it through its module: `import std.math.det` then `det.sqrt(9.0)`.
