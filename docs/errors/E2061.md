# E2061 — a lambda whose parameter types cannot be inferred

```ember,fails
fn main():
    f = fn(a) => a
    println("x")
```

```text
error[E2061]: cannot tell what `a` holds
  = help: annotate it, or write the closure where a `fn(…)` type is expected
  = note: a lambda's parameter types come from the expected function type [TYP-23]
```

## Why

A lambda's parameter types come from the function type it is given to (`[TYP-23]`). Assigned to a plain local there is no such type, and what the body does with `a` could fit any number of types. Ember asks for the type instead of choosing one from the body.

## The fix

Annotate the parameter:

```ember,fixed
fn main():
    f = fn(a: int) => a
    println(f(1))
```
