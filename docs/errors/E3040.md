# E3040 — a name used after it was handed over

```ember,fails
fn main():
    items = [1, 2, 3]
    snapshot = items
    println(items)
    println(snapshot)
```

```text
error[E3040]: `items` was handed over to `snapshot` on line 3 and is used on line 4; to keep both, write `snapshot = copy of items` (a copy of your own) or `snapshot = shares items` (two owners of one value)
 --> page.em:4:5
  |
3 |     snapshot = items
  |                ----- moved here
4 |     println(items)
  |     ^^^^^^^^^^^^^^ used here
  |
  = help: write `snapshot = copy of items` (a copy of your own) or `snapshot = shares items` (two owners), or use `items` before it is handed over
  = note: the view would point at memory whose owner gave it away
  = note: `=` hands a list, a map or a set over; in Python both names would point at one list (Appendix E)
```

## Why

`b = a` with a whole name `a` that owns a value whose type is not `Copy` hands `a` over: `a` ends, and there is
one owner of the list, not two (`[OWN-3]`). Using `items` afterwards would read a value that now belongs to
`snapshot`, so the use is refused, labelled at the hand-over and at the use.

## The fix

To keep both, make a copy of your own, or share the list between two owners:

```ember,fixed
fn main():
    items = [1, 2, 3]
    snapshot = copy of items
    println(items)
    println(snapshot)
```
