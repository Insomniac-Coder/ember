# E3020 — iterable is mutated while the loop borrows it

```ember,fails
fn main():
    values: Array[i32] = Array[i32]()
    values.push(1)
    for value in values.as_span().iter():
        values.push(2)
        println(value)
```

```text
error[E3020]: cannot mutate `values` while it is borrowed by this loop
```

## Why

A `for` loop borrows its iterable until that loop ends. Growing, clearing, or
otherwise mutating the same storage could invalidate the iterator or a value
it yielded, so Safe Ember rejects the mutation as diagnostic shape B2.

This is more specific than E3021/B3: the loop itself, rather than an ordinary
standalone borrow, is what keeps the iterable borrowed.

## The fix

Collect the indices or values first and mutate in a separate pass, use
`retain`/`drain` when those operations fit, or iterate over a fixed index range
whose bound was taken before mutation:

```ember,fixed
fn main():
    values: Array[i32] = Array[i32]()
    values.push(1)
    count = values.len()
    for index in 0..count:
        value = values[index]
        values.push(2)
        println(value)
```
