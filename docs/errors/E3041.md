# E3041 — retired: a value handed over in a loop

`E3041` is no longer emitted. It refused a loop body that hands over a value declared outside the loop, since the next round finds it gone.

Since 0.9.20 it is `E3040`, the code of every use after a hand-over: "`values` is handed over on line 9 and the loop comes round again, so the next round finds it gone; give it a new value before the next round (`values = …`), declare it inside the loop, or hand over a copy of your own: `copy of values`".
