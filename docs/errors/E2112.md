# E2112 — `virtual` in a class that cannot be subclassed

```ember,fails
class FinalThing:
    virtual fn tick():
        pass

fn main():
    println(1)
```

```text
error[E2112]: `FinalThing` cannot be subclassed, so `virtual` on `tick` changes nothing; to let subclasses replace it write `open class FinalThing:`, or remove `virtual`
```

## Why

A class is final unless it is declared `open` or `abstract` (`[CLS-4]`), so no class can replace one of its methods and `virtual`
promises a dispatch nothing can use.

## The fix

Remove `virtual`, or let subclasses replace the method by writing `open class`.

```ember,fixed
open class FinalThing:
    virtual fn tick():
        pass

fn main():
    println(1)
```
