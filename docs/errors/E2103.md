# E2103 — assignment to `self` in a class method

```ember,fails
class Counter:
    value: int

    fn reset():
        this = Counter(0)

fn main():
    c = Counter(5)
    c.reset()
    println(c.value)
```

```text
error[E2103]: cannot assign to `this` in a class method
 --> page.em:5:9
  |
5 |         self = Counter(0)
  |         ^^^^ `this` names the object this method was called on
  |
  = help: to re-point a caller's handle, take it as a `ref mut` parameter [FN-9]
  = note: a method that changes its object holds every field of it until it returns [EXC-15]
```

## Why

Inside a class method `self` is the object the method was called on, for the whole call
(`[CLS-7]`). A `mut self` method holds a write access to every field of that object from entry to
return (`[EXC-15]`), and the accesses to `self`'s fields inside it are covered by it rather than
checked one by one. If `self` could be re-pointed, the rest of the method would write another
object's fields, which nobody holds (ODR-072).

## How to fix

Write the object's fields instead of replacing it:

```ember,fixed
class Counter:
    value: int

    fn reset():
        this.value = 0

fn main():
    c = Counter(5)
    c.reset()
    println(c.value)
```

Or, to make the caller's handle name a different object, take the handle as a `ref mut` parameter
(`[FN-9]`):

```ember,fixed
class Counter:
    value: int

fn replace(ref mut c: Counter):
    c = Counter(0)

fn main():
    c = Counter(5)
    replace(c)
    println(c.value)
```
