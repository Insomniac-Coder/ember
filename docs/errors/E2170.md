# E2170 — reference to a field of a packed struct

```ember,fails
@packed
struct Header:
    tag: u8
    length: u32

fn main():
    h = Header(tag = 1, length = 512)
    r = ref h.length
    println(r)
```

```text
error[E2170]: reference to a field of a packed struct
```

## Why

`@packed` lays a type's fields out with no padding (`[LAY-2]`), so `length`
starts one byte into `Header`, and a `Header` itself may start at any address.
A reference promises an aligned value (`[BRW-9]`), which a field that may sit
at any address cannot keep. The fields of a packed type are read and written by
value instead. The same holds for the references a parameter mode makes: a
`mut` argument, a borrowed argument passed by address, a method's receiver, or
a loop over the field. A field aligned to one byte (`tag`) is never unaligned,
and may be borrowed.

## The fix

Read the field into a local, and borrow the local:

```ember,fixed
@packed
struct Header:
    tag: u8
    length: u32

fn main():
    h = Header(tag = 1, length = 512)
    length = h.length
    r = ref length
    println(r)
```
