# E0114 — `sharedref` without `mut`

```ember,fails
class Player:
    hp: int = 0

fn main():
    p = Player()
    t = sharedref p
    println(t.hp)
```

```text
error[E0114]: `sharedref` is always followed by `mut`: a link that only reads may be held by any number of names
 --> page.em:6:9
  |
6 |     t = sharedref p
  |         ^^^^^^^^^
  |
  = help: write `target: ref Player`; `sharedref` is for a link that may change its target: `target: sharedref mut Player`
```

## Why

`sharedref mut` is a link that may change what it reaches. A link that only reads is a
reference, written `ref`, so `sharedref` is always followed by `mut`.

## The fix

Write `ref` for a name that only reads:

```ember,fixed
class Player:
    hp: int = 0

fn main():
    p = Player()
    t = ref p
    println(t.hp)
```
