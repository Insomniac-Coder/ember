# E3061 — retired: arena allocation outliving its arena

`E3061` is no longer emitted. It refused a value allocated in an arena that is kept or returned where it would outlive the arena.

Since 0.9.20 it is folded into `E3063`, the code of every value kept where it would outlive what it points into or the memory manager's instance it was made in: "arena allocation cannot outlive `arena`".
