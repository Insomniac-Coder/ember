# E2071 — an `SoA` of a type that is not a struct

```ember,fails
fn main():
    scores = SoA[int].with_capacity(16)
```

```text
error[E2071]: `SoA` holds a struct's fields in columns; `i64` is not a struct
```

## Why

`SoA[T]` keeps one column per field of the struct `T`, so code that reads one field of every
element reads one contiguous column. A type that is not a struct has no fields to split.

## The fix

For one value per element, an `Array` is already a single column:

```ember,fixed
fn main():
    scores: Array[int] = []
    scores.push(16)
    println(scores.len())
```
