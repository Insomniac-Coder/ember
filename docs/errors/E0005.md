# E0005 — a keyword used as a name

```ember,fails
fn main():
    type = 3
    println(type)
```

```text
error[E0005]: `type` is a keyword
```

## Why

A keyword is reserved everywhere, so that a reader never has to decide whether `type` or `class` starts a declaration or names something (`[LEX-14]`). The help gives the escape for the case that cannot be avoided, such as a C field called `type`: `r#type`.

## The fix

Pick another name, or write the word as a raw identifier:

```ember,fixed
fn main():
    r#type = 3
    println(r#type)
```
