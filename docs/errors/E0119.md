# E0119 — `owns` as an operand of an operator

```ember,fails
fn main():
    m: Map[int, int] = Map()
    i = 3
    m.insert(owns i * 7, owns i)
    println(m.len())
```

```text
error[E0119]: `owns` here is an operand of `*`, which only reads `i`
  = help: write the product in brackets: `m.insert(owns (i * 7), owns i)`
```

## Why

`owns` binds as tightly as a minus sign, so `owns i * 7` is `(owns i) * 7`: it would hand `i` over to
an operator that only reads its operands, and end `i` before the multiplication. A value computed and
then handed over goes in brackets after `owns`.

## The fix

```ember,fixed
fn main():
    m: Map[int, int] = Map()
    i = 3
    m.insert(owns (i * 7), owns i)
    println(m.len())
```
