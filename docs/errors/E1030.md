# E1030 — two items with the same name

```ember,fails
fn helper() -> int:
    return 1

fn helper() -> int:
    return 2

fn main():
    println(helper())
```

```text
error[E1030]: `helper` is already declared in this module
```

## Why

A call is resolved by name alone, so two functions of one name in one scope would leave the call ambiguous. Ember has no overloading (`[TYP-26]`).

## The fix

Give the functions different names:

```ember,fixed
fn helper() -> int:
    return 1

fn helper2() -> int:
    return 2

fn main():
    println(helper() + helper2())
```
