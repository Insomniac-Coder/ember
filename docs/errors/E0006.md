# E0006 — a language directive for another version

```ember,fails
#! language "0.9.8"

fn main():
    println(1)
```

```text
error[E0006]: language version `0.9.8` is not the current language
```

## Why

Before 1.0 there is exactly one language, the current one, and a source file does not select a version (`[VER-8]`). Accepting `#! language "0.9.8"` would promise a compatibility the compiler does not have.

## The fix

Delete the line:

```ember,fixed
fn main():
    println(1)
```

* `[VER-8]` — selectable language versions begin at 1.0.
