# E2151 — an integer `**` with a negative exponent

```ember,fails
fn main():
    half = 2 ** -1
    println(half)
```

```text
error[E2151]: an integer `**` with a negative exponent
```

## Why

An integer power is exact and stays an integer (`[TYP-30]`). A negative
exponent makes a fraction, which no integer holds. Written as a constant, the
mistake is visible to the compiler; an exponent computed at run time that turns
out negative panics instead.

## The fix

Use a float base when a fraction is meant:

```ember,fixed
fn main():
    half = 2.0 ** -1
    println(half)
```
