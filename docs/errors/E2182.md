# E2182 — a function that returns a value can reach the end of its body

```ember,fails
fn sign(x: int) -> int:
    if x > 0:
        return 1
    elif x < 0:
        return -1

fn main():
    println(sign(0))
```

```text
error[E2182]: this function returns `i64` but can reach the end of its body
```

## Why

Only a `void` function, and a `Result[void, E]` function (which returns
`Ok(())`), has a value when control reaches the end of its body. For any other
return type the end of the body has no value to return, so a path that reaches
it is an error rather than a silent default.

## The fix

Return on every path:

```ember,fixed
fn sign(x: int) -> int:
    if x > 0:
        return 1
    elif x < 0:
        return -1
    return 0

fn main():
    println(sign(0))
```
