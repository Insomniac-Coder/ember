# E3050 — a view of an uninitialised place

```ember,fails
fn main():
    x: i32
    println(x)
```

```text
error[E3050]: `x` is used before it is given a value
 --> page.em:3:13
  |
2 |     x: i32
  |     ------ declared without a value here
3 |     println(x)
  |             ^ used here
  |
  = help: assign a value before reading it
```

## Why

Using a place that is uninitialised on some path, one never given a value there, is `E3050` (`[BRW-7]`): the
bytes behind it hold whatever the stack held before, and reading them would make the program's behaviour depend on
something that is not in the program.

## The fix

Give the place a value before using it:

```ember,fixed
fn main():
    x: i32 = 0
    println(x)
```
