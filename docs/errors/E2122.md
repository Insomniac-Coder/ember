# E2122 — a second owner of a place that has one

```ember,fails
class Player:
    hp: int = 100

fn main():
    players = [Player(), Player()]
    p = shares mut players[1]
    println(p.hp)
```

```text
error[E2122]: `players[1]` has one owner, the list `players`, and no second owner can be made of one element; to let other names own the players, make the list share them from the start: write `players = [shares mut Player(), shares mut Player()]` in place of line 5
```

The same holds for a field (`shares this.items`), a plain parameter (`fn keep(p: Player):
LIST.push(shares p)`, which only reads the caller's player), and `this` in any method (`shares this`,
`shares mut this`): "no second owner of a `Node` is made from inside its own method, since this `Node`
may have one owner; let the caller give one: write `static fn enrol(owns me: shares mut Node):` and
call it `Node.enrol(shares mut n)`".

## Why

Only a whole value is shared (`[RC-1]`). A value with one owner is not counted: no owner is added or
subtracted, and its owner ends it at once, with no count to test. An element of a list, a field, the
caller's value behind a plain parameter and the object a method runs on each have one owner that is
not this function's local, so a second owner made of one would leave that owner ending a value that
another name still owns. `shares` and `shares mut` are written where the value is first made, or
before a local of this function, or before a name that is already an owner; then every owner is
counted from the start.

## The fix

Make the list share its players from the start, so that each element is an owner another name can
add to:

```ember,fixed
class Player:
    hp: int = 100

fn main():
    players = [shares mut Player(), shares mut Player()]
    p = shares mut players[1]
    println(p.hp)
```
