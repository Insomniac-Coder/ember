# L3015 — undocumented unsafe obligation

```ember,fails
pub unsafe fn read_value(x: i32) -> i32:
    return x

fn main():
    pass
```

```text
warning[L3015]: undocumented unsafe obligation
 = help: add `@safety("state the caller's obligation")` above this function
```

## Why

A caller of a public unsafe function must know which condition to establish
before calling it. The function's signature alone does not state that
condition, so leaving the obligation undocumented makes safe wrappers hard to
review.

## The fix

Add an `@safety` statement that says what the caller must guarantee. Replace
the example obligation with the actual condition for the function.

```ember,fixed
@safety("The caller guarantees that x is a valid input.")
pub unsafe fn read_value(x: i32) -> i32:
    return x

fn main():
    pass
```
