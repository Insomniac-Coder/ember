# E2060 — a type that cannot be inferred

```ember,fails
fn main():
    xs = []
    println(xs.len())
```

```text
error[E2060]: cannot infer the element type of `xs`
  = help: annotate the declaration: `xs: Array[int] = []`
```

## Why

Inference is local to a function body (`[TYP-23]`): `[]`, `Map()` and `None` leave a type open, and later uses in the same function may close it. One still open at the end has no answer the compiler could honestly give, and picking one (`int`?) would be a guess that changes the program. The error points at the first use, where the missing information was needed.

## The fix

Say what the list holds, or use it so that it is clear:

```ember,fixed
fn main():
    xs: Array[int] = []
    println(xs.len())
```
