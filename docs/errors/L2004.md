# L2004 — `gen fn` with no `yield`

```ember,fails
gen fn nothing() -> Generator[int]:
    println("ran")

fn main():
    for x in nothing():
        println(x)
```

```text
warning[L2004]: `gen fn nothing` never yields
 = note: a generator with no `yield` produces no items; an ordinary `fn` does the same work [LNT-4]
```

This is a lint, not an error: the program compiles and runs.

## Why

A generator's point is the values it yields. One that never yields produces an
empty sequence however it is driven, and its body runs only when something asks
for the first item: usually a sign that a `yield` was forgotten, or that an
ordinary function was meant (`[CORO-2]`).

## The fix

Yield what the generator is for, or make it an ordinary function:

```ember,fixed
gen fn nothing() -> Generator[int]:
    println("ran")
    yield 1

fn main():
    for x in nothing():
        println(x)
```
