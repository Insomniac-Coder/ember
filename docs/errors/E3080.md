# E3080 — retired: overlapping access through the same handle

`E3080` is no longer emitted. It refused two overlapping long-term accesses to a class field through one handle.

Since 0.9.20 no check of exclusive access runs while a program runs (`[EXC-3]`), and an overlap the compiler sees is an ordinary one: `E3021` for a read or a change of what a read-only name reads, `E3022` for a change through two names.
