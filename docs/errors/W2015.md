# W2015 — float literal has more digits than its type keeps

```ember,fails
fn main():
    x: f32 = 0.123456789012
    println(x)
```

```text
warning[W2015]: float literal loses precision at `f32`
 --> page.em:2:14
  |
2 |     x: f32 = 0.123456789012
  |              ^^^^^^^^^^^^^^ `0.123456789012` becomes `0.12345679104328156`
  |
  = help: write `0.123456789012f64` to keep it, or fewer digits to accept `f32`
```

## Why

A float literal that receives `f32` or `f16` and has more significant digits than the type keeps (more than 9 for
`f32`, 5 for `f16`) is rounded to the type, so the digits past that point are lost (`[LEX-17a]`). The warning
offers the `f64` spelling, the type that keeps them. A literal such as `0.1` is not warned about: the program
chose the type, and every decimal literal is rounded to it.

## The fix

Write the digits the type keeps, or use `f64`:

```ember,fixed
fn main():
    x: f64 = 0.123456789012
    println(x)
```
