# E2020 — mismatched types

```ember,fails
fn main():
    ready: bool = "yes"
    println(ready)
```

```text
error[E2020]: expected `bool`, found `StrView`
```

## Why

Ember converts implicitly in one place only: an untyped literal takes the type its context expects (`[TYP-4]`). Everything else is the type it is, so a value of one type where another is wanted is written out, never guessed. The same code covers the other places a conversion would be silent and wrong: a lambda parameter whose word differs from its function type's, a `weakref` link used without opening it, an integer cast to an enum, and an `unsafe fn` where a safe one is required (`[TYP-45]`, `[TYP-6]`, `[UNS-12]`).

## The fix

Give the value the type the place wants:

```ember,fixed
fn main():
    ready: bool = true
    println(ready)
```
