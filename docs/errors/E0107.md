# E0107 — a jump expression used as an operand

```ember,fails
fn g(b: int) -> int:
    return 1 + return 2

fn main():
    println(g(1))
```

```text
error[E0107]: a jump expression may not be an operand
```

## Why

`return`, `break` and `continue` leave the function or loop, so nothing is left to use the value of `1 + return 2`. A jump is a whole statement, or the whole body of a lambda, a match arm or a conditional branch, never part of a larger expression (`[GRM-16]`).

## The fix

Put the jump on its own, with the operand bound first or written inside it:

```ember,fixed
fn g(b: int) -> int:
    return 1 + 2

fn main():
    println(g(1))
```
