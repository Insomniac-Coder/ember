# E2140 — a change to something that is not a place

```ember,fails
fn main():
    xs = [1, 2, 3]
    xs[0..2] = [5, 6]
    println(xs)
```

```text
error[E2140]: assignment target is not a place
 --> page.em:3:5
  |
3 |     xs[0..2] = [5, 6]
  |     ^^^^^^^^ this is a value, not somewhere to store one
  |
  = help: assign the elements one at a time (`xs[i] = v`)
  = note: a slice is a view of the elements; Ember has no slice assignment
```

## Why

A change, a `ref mut` name and a hand-over require a place (`[EXP-5]`). A slice is a view, so writing to one
would fill a temporary that ends with the line and leave the array unchanged; the compiler says so instead
of losing the change.

## The fix

Change the places themselves, here the elements one at a time:

```ember,fixed
fn main():
    xs = [1, 2, 3]
    xs[0] = 5
    xs[1] = 6
    println(xs)
```
