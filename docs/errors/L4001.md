# L4001 — allocation in a hot loop

```ember,fails
fn main():
    total = 0
    for i in 0..1000:
        label = String.from("item")
        total += label.len() + i
    println(total)
```

```text
warning[L4001]: allocation in a hot loop
```

## Why

Allocating and freeing memory costs far more than the arithmetic around it, and a loop that makes
a new `String`, list or object on every turn pays it every turn. An innermost loop is the one the
compiler judges hot: it runs most often, so that is where the cost adds up.

## The fix

Make the value once, before the loop, and reuse it; `clear()` empties a collection and keeps its
storage for the next turn.

```ember,fixed
fn main():
    total = 0
    label = String.from("item")
    for i in 0..1000:
        total += label.len() + i
    println(total)
```
