# E2228 — retired: callable parameter mode mismatch

`E2228` is no longer emitted. It reported a function value given where a function type with other parameter words is expected: the callback `fn(x) => x` supplies `fn(i32) -> i32` where `fn(ref mut i32) -> i32` is required.

Since 0.9.20 that case is `E2020`, a value that is not of the type that was expected (`[CLO-3]`, `[FN-6a]`): callable parameter modes are part of the callable type, and a parameter written with no word is not interchangeable with `ref mut`. The message and the help are as they were; only the code changed.
