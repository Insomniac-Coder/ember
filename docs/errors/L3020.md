# L3020 — a `safe:` block outside unsafe code

```ember,fails
fn main():
    safe:
        println(1)
```

```text
warning[L3020]: this `safe:` block is not inside unsafe code, so it changes nothing
 = help: remove `safe:` and keep its statements [UNS-12]
```

This is a lint, not an error: the program compiles and runs.

## Why

An `unsafe fn` is unsafe as a whole, and so is the inside of an `unsafe:` block (`[UNS-12]`). A `safe:`
block marks code in there that is to be checked as safe code. Code outside unsafe code is checked as
safe code already, so a `safe:` block there says something that is true anyway, and a reader looks for
the unsafe code it is in.

## The fix

Remove `safe:` and keep its statements:

```ember,fixed
fn main():
    println(1)
```
