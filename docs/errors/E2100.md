# E2100 — a class field is used before it is initialized

```ember,fails
class Point:
    x: i32
    y: i32

    fn init(mut self, x: i32):
        self.x = self.y
        self.y = x

fn main():
    point = Point(1)
    println(point.x)
```

```text
error[E2100]: field `y` is read before it is initialized
```

## Why

A class constructor may not make an object reachable while one of its
non-defaulted fields is still uninitialized. Reading such a field would treat
storage that has not received a valid value as an ordinary initialized value,
which could violate both the field's type invariant and its destruction
obligations. The check is attached to the field read so the diagnostic points
at the operation that would observe the invalid state.

## The fix

Initialize each field before reading it, and ensure every field is initialized
on every constructor path:

```ember,fixed
class Point:
    x: i32
    y: i32

    fn init(mut self, x: i32, y: i32):
        self.x = x
        self.y = y

fn main():
    point = Point(1, 2)
    println(point.x + point.y)
```
