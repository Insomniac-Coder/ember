# L1001 — unused binding

```ember,fails
fn main():
    unused = 5
    println(1)
```

```text
warning[L1001]: `unused` is never read
 --> page.em:2:5
  |
2 |     unused = 5
  |     ^^^^^^^^^^ declared here and never used
  |
  = help: remove it, or rename it `_unused` if that is deliberate
```

## Why

A local that is never read on any path does nothing (`[LNT-1]`), and it is usually a sign that something was
left out: a value that was meant to be used, or a name that was replaced by another. A name that starts with `_`
says the omission is deliberate and is exempt. The program still compiles; `L1001` is reported by `ember build`
and `ember check` (`[LNT-3]`).

## The fix

Use the binding, remove it, or start its name with `_`:

```ember,fixed
fn main():
    _unused = 5
    println(1)
```
