# L3016 — safety text still reads TODO

```ember,fails
@safety("TODO: state the caller's obligation")
pub unsafe fn read_value(x: i32) -> i32:
    return x

fn main():
    pass
```

```text
warning[L3016]: `@safety` text still reads `TODO`
```

## Why

The placeholder records that the caller's obligation has not been specified.
Readers cannot establish whether a call meets an unstated condition.

## The fix

Replace the placeholder with the actual condition a caller must satisfy.

```ember,fixed
@safety("The caller guarantees that x is a valid input.")
pub unsafe fn read_value(x: i32) -> i32:
    return x

fn main():
    pass
```
