# E0102 — a membership test chained

```ember,fails
fn main():
    xs = [1, 2]
    ys = [3, 4]
    println(1 in xs in ys)
```

```text
error[E0102]: `is` and `in` may not appear in a comparison chain
```

## Why

The comparisons `<`, `==` and the rest chain as in Python (`a < b <= c`), but `a in b in c` would have to mean either `(a in b) in c` or `a in b and b in c`, and Python readers disagree about which. Ember refuses the chain and asks for the tests to be written separately (`[GRM-23]`, `[GRM-25]`).

## The fix

Write each test and join them with `and`:

```ember,fixed
fn main():
    xs = [1, 2]
    ys = [3, 4]
    println(1 in xs and 1 in ys)
```
