# E2114 — `owns` on a class type

```ember,fails
class Player:
    name: String

class Team:
    captain: owns Player

fn main():
    println("ready")
```

```text
error[E2114]: a `Player` object always lives in its own block; remove `owns`: `captain: Player`
```

## Why

`owns T` puts a value in a block of its own, with one owner (`[TYP-45]`, `[OWN-10]`). A class object
is already made that way: it lives in its own heap block with a header, and the place it is stored in
is its one owner unless a line says `shares` (`[CLS-1]`). `owns` before a class type would say what the
type already says, and would suggest that a class and a struct are held differently when they are not.

## The fix

Write the class type alone. The place is the object's owner:

```ember,fixed
class Player:
    name: String

class Team:
    captain: Player

fn main():
    println("ready")
```
