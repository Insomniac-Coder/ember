# E5090 — inline assembly is not supported by the C backend

```ember,fails
fn main():
    unsafe:  # SAFETY: a test of the refusal
        asm("nop")
```

```text
error[E5090]: inline assembly is not supported by the C backend
```

## Why

Inline assembly is `unsafe asm("…", …)` on a toolchain that supports it. The C backend writes
portable C, which has no inline assembly: MSVC on x64 accepts none, and gcc's and clang's forms are
not portable between targets. So the instructions cannot be placed where they are written.

## The fix

Write the instructions in a C or assembly file that the package links, and declare the function
there `extern "C"`; call it like any foreign function.

```ember,fixed
unsafe extern "C":  # SAFETY(ffi): each declaration below matches its C definition
    safe fn abs(x: i32) -> i32

fn main():
    println(abs(-3))
```
