# E2220 — `yield` outside a `gen fn`

```ember,fails
fn numbers() -> int:
    yield 1
    return 2

fn main():
    println(numbers())
```

```text
error[E2220]: `yield` outside a `gen fn`
 = help: declare the function `gen fn … -> Generator[Y]` [CORO-1]; a lambda or a local function inside a generator is a function of its own, and cannot yield for it [CORO-2]
```

## Why

A `yield` suspends the function it is in and hands a value to whoever resumes
it. Only a generator has somewhere to be suspended to: calling a `gen fn` builds
its frame, a value that holds where the body stopped, and `next` resumes it
(`[CORO-1]`). An ordinary function's frame lives on the stack only while it
runs, so it has nowhere to keep its place. A lambda inside a generator is a
function of its own and can no more suspend its creator than any other call
can.

## The fix

Declare the function a generator. It then returns `Generator[Y]`, which a `for`
loop, an adapter or `next` drives:

```ember,fixed
gen fn numbers() -> Generator[int]:
    yield 1
    yield 2

fn main():
    for n in numbers():
        println(n)
```
