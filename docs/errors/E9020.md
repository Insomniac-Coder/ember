# E9020 — the imports of one target disagree on the C++ runtime

```toml
[package]
name = "page"
version = "0.1.0"

[cpp.engine]
flags = ["/MDd"]

[cpp.tools]
flags = ["/MD"]
```

```cpp,file=engine.hpp
#pragma once

inline int twice(int x) noexcept { return 2 * x; }
```

```cpp,file=tools.hpp
#pragma once

inline int thrice(int x) noexcept { return 3 * x; }
```

```ember,fails
import cpp "engine.hpp" with (project = "engine") as engine
import cpp "tools.hpp" with (project = "tools") as tools

fn main():
    unsafe:  # SAFETY(ffi): scalar calls
        println(engine.twice(2), tools.thrice(2))
```

```text
error[E9020]: the imports of `engine.hpp` and `tools.hpp` disagree on the C++ runtime
 --> page.em:2:1
  |
2 | import cpp "tools.hpp" with (project = "tools") as tools
  | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  |
  = help: build the C++ projects with one runtime, and name it in each one's flags
  = note: `engine.hpp` is compiled with `/MDd`, and `tools.hpp` with `/MD`
  = note: one target's translation units are compiled with one runtime switch, `_DEBUG` and `_ITERATOR_DEBUG_LEVEL`, which change the C++ standard library's layout [BLD-FFI-1b]
```

## Why

MSVC's runtime-library switch (`/MD`, `/MDd`, `/MT`, `/MTd`), `_DEBUG` and `_ITERATOR_DEBUG_LEVEL`
decide which C runtime's heap a translation unit allocates from and how the C++ standard library lays
out its types: a `std::vector` of the debug runtime carries fields the release one has not. The
build therefore inherits them, byte for byte, from the C++ project, and compiles every translation
unit of the target with them (`[BLD-FFI-1b]`): Ember's own C, the runtime, and each import's thunks.
Two imports whose projects name different ones leave no single runtime to inherit; linking them
anyway would let one side free what the other's heap allocated.

## The fix

Build the C++ projects with one runtime, and name it in each project's flags.

```toml
[package]
name = "page"
version = "0.1.0"

[cpp.engine]
flags = ["/MDd"]

[cpp.tools]
flags = ["/MDd"]
```

```ember,fixed
import cpp "engine.hpp" with (project = "engine") as engine
import cpp "tools.hpp" with (project = "tools") as tools

fn main():
    unsafe:  # SAFETY(ffi): scalar calls
        println(engine.twice(2), tools.thrice(2))
```
