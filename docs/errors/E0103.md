# E0103 — match arms mixing statement and expression form

```ember,fails
fn main():
    x = 1
    y = match x:
        1 => 10
        _:
            println(0)
    println(y)
```

```text
error[E0103]: match arms mix statement and expression form
```

## Why

A `match` with `pattern: block` arms is a statement and one with `pattern => expression` arms is an expression (`[GRM-10]`). One `match` cannot be both: the first arm decides whether a value is produced, and an arm of the other form would either produce none or run no statements.

## The fix

Use one form for every arm:

```ember,fixed
fn main():
    x = 1
    y = match x:
        1 => 10
        _ => 0
    println(y)
```
