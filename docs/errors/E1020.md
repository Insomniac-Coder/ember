# E1020 — a name declared twice in one block

```ember,fails
fn main():
    z: int = 1
    z: int = 2
    println(z)
```

```text
error[E1020]: `z` is already declared in this block
```

## Why

A declaration may shadow a name from an enclosing block, but redeclaring one in the same block would silently replace the earlier variable and everything that meant it (`[GRM-4]`).

## The fix

Assign to the name, or declare the second one in a nested block:

```ember,fixed
fn main():
    z: int = 1
    z = 2
    println(z)
```
