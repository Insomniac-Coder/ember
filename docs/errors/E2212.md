# E2212 — range endpoints are not constants of the representation, or are inverted

```ember,fails
type Backwards = f32 in 1.0 ..= 0.0

fn main():
    println(1)
```

```text
error[E2212]: the range is inverted: the low endpoint is above the high one
 --> page.em:1:25
  |
1 | type Backwards = f32 in 1.0 ..= 0.0
  |                         ^^^^^^^^^^^
  |
```

## Why

A `type` alias with an `in` clause is a numeric type restricted to a range whose endpoints are constants of the
representation (`[RNG-1]`). The compiler removes run-time checks by reasoning about the range (`[RNG-4]`), which
needs both endpoints known and in order; an inverted range contains no value at all.

## The fix

Write the lower endpoint first:

```ember,fixed
type Unit = f32 in 0.0 ..= 1.0

fn main():
    println(1)
```
