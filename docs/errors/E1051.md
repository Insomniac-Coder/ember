# E1051 — `read` visibility on something that is not a field

```ember,fails
pub(read) fn f() -> int:
    return 1

fn main():
    println(f())
```

```text
error[E1051]: `read` visibility is valid on fields only
```

## Why

`pub(read)` says a field may be read wherever a `pub` one could and written only from its own module (`[MOD-7]`). That split means something only for a field, which is a place that can be read and written. A function, a type or a constant has no "read but not write": it is visible or it is not. Accepting the word there would let a reader believe it restricts something when it restricts nothing (`[PHIL-12]`).

## The fix

Write the visibility that says what you mean. A function is `pub` or `pub(package)`:

```ember,fixed
pub fn f() -> int:
    return 1

fn main():
    println(f())
```
