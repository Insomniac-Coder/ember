# E9010 — unknown lint key in the package manifest

The failing example is compiled in a package whose `ember.toml` contains:

```toml
[lints]
not_a_lint = "warn"
```

```ember,fails
fn main():
    println(42)
```

The compiler points at the invalid manifest line:

```text
error[E9010]: unknown lint `not_a_lint` in `[lints]`
 --> ember.toml:2:1
```

## Why

Lint configuration expresses a package's checked guarantees. Silently ignoring
a misspelled lint name would make a package appear protected by a check that it
never enabled, which is worse than refusing the build at configuration time.

## The fix

Replace the unknown key with a lint code or documented descriptive key. The
fixed example is compiled with this `ember.toml`:

```toml
[lints]
unused = "warn"
```

```ember,fixed
fn main():
    println(42)
```
