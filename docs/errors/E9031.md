# E9031 — invalid `reload` value

```toml
[build]
reload = "sometimes"
```

```ember,fails
fn main():
    println("hello")
```

```text
error[E9031]: `sometimes` is not a `reload` value
```

## Why

`[build] reload` decides how a package is built when hot reload is on: which functions are reached
through permanent thunks, whether instances carry the larger header that lets them migrate. A word
the compiler does not know would leave that to a guess, and a build that guesses its own layout
cannot be reloaded safely later.

## The fix

Write one of the four values: `"opt-in"` (only what `@reloadable` names), `"all"` (everything but
what `@noreload` names), `"bodies"` (function bodies only, no migration) or `"none"`.

```toml
[build]
reload = "all"
```

```ember,fixed
fn main():
    println("hello")
```
