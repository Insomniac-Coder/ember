# E2130 — a `const` of a type that owns heap memory

```ember,fails
const NAMES: Array[int] = [1, 2, 3]

fn main():
    println(NAMES.len())
```

```text
error[E2130]: a `const` cannot hold a `Array[i64]`
 --> page.em:1:14
  |
1 | const NAMES: Array[int] = [1, 2, 3]
  |              ^^^^^^^^^^
  |
  = help: declare `static NAMES: Array[i64] = â€¦`: one value, at one address
  = note: a `const` is copied into each use, so it is `Copy` and owns no heap memory [V.7]
```

## Why

A `const` is evaluated during compilation and inlined at each use (§V.7, `[CT-1]`), so its type is `Copy`, a
`StrView`, a `bytes` literal type or a fixed array of those. A value that owns heap memory
(an `Array`, a `String`, a `Map`) has to be made while the program runs and freed when it ends; a
`static` is the item that holds such a value once.

## The fix

Use a `static` for a value that owns heap memory, or a fixed array `[T; N]` for a table of numbers:

```ember,fixed
const NAMES: [int; 3] = [1, 2, 3]

fn main():
    println(NAMES[0])
```
