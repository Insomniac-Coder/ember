# E0106 — a multi-statement lambda inside brackets

```ember,fails
fn apply(f: fn(i32) -> i32, v: i32) -> i32:
    return f(v)

fn main():
    println(apply(fn(x: i32): y = x * 2
        return y, 4))
```

```text
error[E0106]: a multi-statement closure cannot be written inside brackets
```

## Why

Inside brackets indentation is not significant (`[LEX-6]`), so a lambda's body can be only the one simple statement that ends at the next `,` or closing bracket (`[LEX-6a]`). A body of several statements has no way to say where it ends (`[GRM-17]`).

## The fix

Declare a local function on the preceding line and pass its name:

```ember,fixed
fn apply(f: fn(i32) -> i32, v: i32) -> i32:
    return f(v)

fn main():
    fn double(x: i32) -> i32:
        y = x * 2
        return y
    println(apply(double, 4))
```
