# E2031 — `from` names a parameter the result cannot point into

```ember,fails
fn pick(n: int) -> StrView from n:
    return "a"

fn main():
    println(pick(1))
```

```text
error[E2031]: `from` names `n`, which a result cannot point into
  = help: name a parameter the result can point into, or remove `from` and let the parameters decide (LT-1)
```

## Why

`from` says what a view result points into, so that callers know what must stay alive while the result does (`[LT-1a]`). A plain `Copy` parameter such as an `int` is passed as a copy: nothing of the caller's lives on in the result, so there is nothing for the result to point into. The same holds for an `owns` parameter that is not itself a view, which the function consumes.

## The fix

Name a parameter the view can point into, or drop `from` when the parameters decide. Here the result is a view of the `StrView` parameter:

```ember,fixed
fn pick(s: StrView) -> StrView from s:
    return s

fn main():
    println(pick("a"))
```
