# E0100 — an unexpected token: a one-element tuple

```ember,fails
fn main():
    t = (5,)
    println(t)
```

```text
error[E0100]: a tuple has two or more elements; write `e`
```

## Why

`E0100` is the general error for a token the grammar does not allow. Among its cases is the one-element tuple `(e,)`, the Python spelling of a 1-tuple: Ember's tuple has two or more elements, so `(5,)` could only be a mistake or a habit, and it is refused (`[GRM-29]`). The same holds for one expression and a comma in an `expr_list`, a `target_list` or a pattern.

## The fix

Write the expression itself, or give the tuple a second element:

```ember,fixed
fn main():
    t = 5
    println(t)
```
