# W5054 — an unexercised foreign fact

```ember,fails
unsafe extern "C":
    @ffi(effects=[])
    safe fn abs(x: i32) -> i32
    @ffi(effects=[])
    safe fn imaxabs(x: i64) -> i64

@test
fn magnitude():
    assert(abs(-5) == 5)

fn main():
    println(imaxabs(-3))
```

```text
warning[W5054]: `imaxabs`'s effect facts were never exercised: no test called it
 --> src/main.em:5:5
  |
5 |     safe fn imaxabs(x: i64) -> i64
  |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  |
  = note: no Alloc, no Lock, no Block, no Io: unexercised, so they count for nothing [FFI-37b]
```

`ember test --instrument-ffi` reports it, after the tests ran.

## Why

An instrumented run grades a foreign function's effect facts by what it saw
while the function ran. A function no test called was never seen: the run has
nothing to say about it, and grading its facts `instrumented` would turn
silence into evidence. So they are reported `unexercised` and count for
nothing; the facts stay what they were, asserted. The warning names the
function so a test can be written for it.

## The fix

Call the function from a test, on the paths that matter:

```ember,fixed
unsafe extern "C":
    @ffi(effects=[])
    safe fn abs(x: i32) -> i32
    @ffi(effects=[])
    safe fn imaxabs(x: i64) -> i64

@test
fn magnitude():
    assert(abs(-5) == 5)
    assert(imaxabs(-3) == 3)

fn main():
    println(imaxabs(-3))
```
