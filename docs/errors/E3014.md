# E3014 — a scope not bound by `with`, or moved

```ember,fails
import std.thread

fn main():
    s = thread.scope()
```

```text
error[E3014]: `thread.scope()` must be bound by `with`
```

## Why

A scope's threads may borrow the block's places, so the scope must end exactly where the block
does: its end joins every thread before the block's places go away. A `with` binding is what ties
the two together; a scope held anywhere else, or moved out of its binding, could outlive the places
its threads borrow.

## The fix

Bind the scope with `with`, and use it there; `scope.spawn` borrows it:

```ember,fixed
import std.thread

fn main():
    total = 0
    with scope = thread.scope():
        h = scope.spawn(fn() => 2 + 3)
        total += h.join()
    println(total)
```
