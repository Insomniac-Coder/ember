# E0120 — `ref mut` among a function's capture words

```ember,fails
fn main():
    total = 0
    add = fn(x: int) ref mut total: total += x
    add(2)
    println(total)
```

```text
error[E0120]: remove `ref mut total`: it is not a capture word
  = help: without a word the function already uses the real `total`, and may change it: `fn(): total += 1`
```

## Why

The words after a function's brackets say how it keeps a name other than as the real variable: a copy
of its own (`copy of`), the value handed over (`owns`), a share of it. A name with no word is the real
variable, which the function reads and may change, so `ref mut` would say what is already so.

## The fix

```ember,fixed
fn main():
    total = 0
    add = fn(x: int): total += x
    add(2)
    println(total)
```
