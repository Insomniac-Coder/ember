# E5020 — `str` is not a C string

```ember,fails
fn main():
    name: cstr = "Ember"
```

```text
error[E5020]: expected `cstr`, found `str`
 = help: use a `c"…"` literal or convert with `.to_cstring()`
```

## Why

An Ember `str` carries a byte length. A C string instead ends at a NUL byte.
Passing an ordinary `str` pointer to C would let C read past the view's end.
The two types therefore do not coerce to one another.

## The fix

Use a `c"…"` literal for fixed text. It has type `cstr`, stores the terminating
NUL, and cannot contain an interior NUL.

```ember,fixed
fn main():
    name: cstr = c"Ember"
```

For runtime text, `.to_cstring()` is the allocating conversion specified by
`[FFI-15]`; it remains an implementation gap.
