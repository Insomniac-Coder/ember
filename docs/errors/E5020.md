# E5020 — `str` is not a C string

```ember,fails
fn main():
    name: cstr = "Ember"
```

```text
error[E5020]: expected `cstr`, found `str`
 = help: use a `c"…"` literal, or handle `.to_cstring()` and pass the owned value's `.as_cstr()`
```

## Why

An Ember `str` carries a byte length. A C string instead ends at a NUL byte.
Passing an ordinary `str` pointer to C would let C read past the view's end.
The two types therefore do not coerce to one another.

## The fix

Use a `c"…"` literal for fixed text. It has type `cstr`, stores the terminating
NUL, and cannot contain an interior NUL.

```ember,fixed
fn main():
    name: cstr = c"Ember"
```

For runtime text, handle the `Result` from `.to_cstring()`, keep the successful
`CString` in a local, and pass its `.as_cstr()` borrow to C. The local must
remain alive for the call. An interior NUL returns `NulError` with its first
byte offset; it never truncates the text.
