# E3062 — a result that points into something its `from` does not name

```ember,fails
struct Parser:
    buf: StrView

    fn next_word(src: StrView) -> StrView from src:
        return this.buf

fn main():
    p = Parser(buf="a b")
    println(p.next_word("c"))
```

```text
error[E3062]: `next_word` returns a view of `this.buf`, but its first line says `from src`
 --> page.em:5:16
  |
4 |     fn next_word(src: StrView) -> StrView from src:
  |        --------- `this` is the parameter it points into
5 |         return this.buf
  |                ^^^^^^^^ returned here
  |
  = help: return a view of `src`, or write `-> StrView from buf`
  = note: `from` is what ties a result to a parameter its first line's rule would not (LT-1a)
```

## Why

`-> T from name` replaces the rule the compiler would apply: the result points into exactly the named parameter,
or the named field of `this` (`[LT-1a]`). The caller trusts that line alone to know what the result keeps borrowed,
so a body that gives a view of anything else would let the caller release something that is still pointed into.

## The fix

Return a view of what `from` names, or write the `from` that names what the body returns:

```ember,fixed
struct Parser:
    buf: StrView

    fn next_word(src: StrView) -> StrView from buf:
        return this.buf

fn main():
    p = Parser(buf="a b")
    println(p.next_word("c"))
```
