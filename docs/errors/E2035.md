# E2035 — a condition must be `bool`

```ember,fails
fn main():
    xs = [1, 2]
    if xs:
        println("some")
```

```text
error[E2035]: condition must be `bool`
  = help: a container is not a condition: write `not xs.is_empty()`
```

## Why

Ember has no truthiness (`[CTL-0]`). Whether an empty list, a zero or a `None` counts as "false" differs from one language to the next and the difference is a classic source of bugs, so a condition says what it tests. The message carries the fix for the type it found: `not xs.is_empty()` for a container or text, `x is not None` for an `Option`, `x != 0` for a number.

## The fix

Write the test:

```ember,fixed
fn main():
    xs = [1, 2]
    if not xs.is_empty():
        println("some")
```
