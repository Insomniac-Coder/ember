# E5063 — foreign bytes handed to a `StrView` unvalidated

```ember,fails
pub extern "C" fn take(s: StrView) -> i32:
    return 0

fn main():
    pass
```

```text
error[E5063]: `s` would be text C never validated; take `s: Span[u8]` and write `s.to_str()?` for the `StrView` ([TXT-2])
 --> page.em:1:24
  |
1 | pub extern "C" fn take(s: StrView) -> i32:
  |                        ^^^^^^^^^^
  |
  = help: take `s: Span[u8]` and write `s.to_str()?` for the `StrView` [TXT-2]
```

## Why

A `StrView` is always valid UTF-8, and nothing becomes one without validation. An export
taking a `StrView` would take whatever bytes C passes as text.

## The fix

Take the C string and validate it where the text is used:

```ember,fixed
pub extern "C" fn take(s: CStrView) -> i32:
    return 0

fn main():
    pass
```

The message's line, `s: Span[u8]` with `s.to_str()?`, builds once an export's `Span`
parameters are built (`[FFI-31b]`); until then such an export is `E5015`.
