# E2040 — an interface bound that is not met

```ember,fails
interface Named:
    fn name() -> int

struct Dog:
    x: int

[T: needs Named]
fn show(v: ref T):
    println(v.name())

fn main():
    d = Dog(1)
    show(ref d)
```

```text
error[E2040]: `Dog` does not implement `Named`, which `T` requires
```

## Why

A bound is what a generic function promises to use of its type parameter and what its callers promise to supply (`[TYP-17]`). Checking it at the call, where the type is known, gives an error that names the type and the interface, instead of one from inside the generic body about a method that does not exist. The same code covers an implementation that does not meet its interface's parents, and a generic whose body needs a bound its first line does not write.

## The fix

Implement the interface for the type:

```ember,fixed
interface Named:
    fn name() -> int

struct Dog implements Named:
    x: int

    fn name() -> int:
        return this.x

[T: needs Named]
fn show(v: ref T):
    println(v.name())

fn main():
    d = Dog(1)
    show(ref d)
```

## See also

* `[TYP-17]` — bounds, and `needs`.
* `[IFC-6]` — a `pub` generic writes its bounds.
* `[STD-9]` — a value printed (`print`, `println`, `eprint`, `eprintln`, `format_to`) needs
  `Printable`, which every type with `Display` or `Debug` has; a type with neither is `E2040`, and
  so is `Printable` written by hand, which is the compiler's.
