# E2215 — a range-typed value built outside the permitted set

```ember,fails
type Percent = u8 in 0 ..= 100

fn from_input(x: u8) -> Percent:
    return x
```

```text
error[E2215]: a `Percent` cannot be built from a value this is not known to be in range

  = help: `Percent.clamped(x)` is total; `Percent.checked(x)` returns a `Result` when the difference matters
  = note: the ways to make a range value are a constant in range, `checked`, `clamped`, a value whose known range fits, and a copy [RNG-10]
```

## Why

`[RNG-10]` calls this "the construction set is closed", and closing it is what
makes the type worth having. `[RNG-4]` is allowed to *assume* that a value of a
range type is in range — that assumption is what lets it discharge an overflow
check under `[TYP-8]` or a bounds check under `[OPT-2]`. An assumption is only
as good as the routes into the type, so every route is enumerated: a constant
the compiler placed in range, `T.checked`, `T.clamped`, a value whose known
range is contained in the target's, and a copy of an already-valid value.

A `u8` parameter is none of those. Its value arrives from somewhere the
compiler cannot see, and "it is probably fine" is not a route.

The escape is `unsafe T.new_unchecked(v)`, which is `unsafe` for the ordinary
reason: the programmer is asserting what the machine cannot check, and
`[RNG-9]` makes an out-of-range value undefined behaviour exactly as a `bool`
that is neither 0 nor 1 is.

## The fix

Pick the construction that matches what should happen to an out-of-range input.

```ember,fixed
type Percent = u8 in 0 ..= 100

# Pull it to the nearest edge. Total: no failure mode, and on the C backend
# two compares.
fn from_slider(x: u8) -> Percent:
    return Percent.clamped(x)

# Or keep the difference between "it was 40" and "it was 200". `checked`
# returns `Result[Percent, RangeError]`; `RangeError` is not yet a name a
# program can write, so the result is matched rather than named.
fn from_file(x: u8) -> u32:
    match Percent.checked(x):
        Ok(p) => return p
        Err(e) => return 0

fn main():
    v: u32 = from_slider(200)
    print(v)
    print(from_file(40))
    print(from_file(200))
```
