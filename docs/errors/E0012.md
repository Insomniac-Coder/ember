# E0012 — a bidirectional format character in the source

```ember,fails
fn main():
    # an override ‮ here
    println("ok")
```

```text
error[E0012]: line 2 holds U+202E, which reorders how the line is shown
 --> page.em:2:19
  |
2 |     # an override ‮ here
  |                   ^
  |
  = help: write the text as an escape, `\u{202E}`, inside the literal, or remove it
```

## Why

Characters U+202A to U+202E and U+2066 to U+2069 change the order in which a line is shown, so
a reviewer could read code the compiler reads differently. They are refused anywhere in a file,
a comment or a literal included; it is the one diagnostic a comment produces.

## The fix

Remove the character, or write it as an escape inside a literal:

```ember,fixed
fn main():
    # an override here
    println("ok")
```
