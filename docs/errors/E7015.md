# E7015 — a one-thread value where any thread may reach it

```ember,fails
class Stats:
    draws: Cell[int] = Cell(0)

fn main():
    _stats = thread_shared Stats()
```

```text
error[E7015]: `Stats.draws` is a `Cell[i64]`, which several threads may not read at once, and a `thread_shared Stats` may be read from any thread; write `draws: Mutex[Cell[i64]]` in `Stats`
```

## Why

The counts of a `shares` or `shares mut` owner and of a `weakref` link are plain memory, and a `Cell`
changes without a lock. Each is safe because one thread uses it. A value any thread may hold cannot
contain one, and such a value cannot be handed to another thread.

## The fix

Give the part a type threads may share:

```ember,fixed
from std.sync import Atomic

class Stats:
    draws: Atomic[int] = Atomic(0)

fn main():
    _stats = thread_shared Stats()
```
