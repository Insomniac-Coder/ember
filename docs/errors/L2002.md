# L2002 — large `Copy` value passed by value

```ember,fails
@derive(Copy)
struct Samples:
    values: [f64; 64]
    count: int

fn count_of(owned s: Samples) -> int:
    return s.count

fn main():
    println(count_of(Samples([0.0; 64], 2)))
```

```text
warning[L2002]: `s` is a 520-byte `Copy` value passed by value
```

## Why

An `owned` parameter is a copy the callee keeps, and a `Copy` value that size is copied in full on
every call, even when the callee only reads one field. A borrowed parameter of the same type is
passed by address (`[BRW-8]`): the callee reads the caller's value in place, and nothing is copied.

## The fix

Take the parameter borrowed. `[lints] large_copy = { threshold = N }` sets the size, in bytes, above
which the lint reports (256 by default).

```ember,fixed
@derive(Copy)
struct Samples:
    values: [f64; 64]
    count: int

fn count_of(s: Samples) -> int:
    return s.count

fn main():
    println(count_of(Samples([0.0; 64], 2)))
```
