# E4041 — a `@noio` function reaches I/O

```ember,fails
@noio
fn shout(n: int) -> int:
    println(n)
    return n

fn main():
    println(shout(1))
```

```text
error[E4041]: `@noio` function `shout` reaches I/O
  = note: shout -> console output
```

## Why

Input and output are slow, can fail, and touch the world outside the program. `@noio` marks a
function whose result depends only on its arguments' data and that leaves no trace outside the
program, so it can be cached, retried or run anywhere. Printing is output, even to the console.

## The fix

```ember,fixed
@noio
fn twice(n: int) -> int:
    return n * 2

fn main():
    println(twice(1))
```

Return the value and print it in the caller.
