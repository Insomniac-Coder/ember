# E3064 — reserved legacy multi-region diagnostic

`E3064` is retained in the registry so its historical identity cannot be
reused, but the 0.9.6 development target reserves it and a conforming compiler
does not emit it.

Before multi-region view structs, this code reported a view aggregate that
would have needed independently tracked field regions. Ember now represents
those fields with separate compile-time region slots. A use of a field keeps
that field's source live rather than imposing the former whole-aggregate
intersection.

Current programs receive the diagnostic for the rule they actually violate:

- `E3021` for an ordinary shared/mutable borrow conflict involving a live
  field; or
- `E3065` when a multi-region result has no sound field-to-source provenance
  summary.

This page remains as historical documentation. It intentionally has no
executable `ember,fails` example because no current program should trigger a
reserved diagnostic.

## Why it remains registered

Stable diagnostic identities are not recycled. Keeping the registry entry and
this page prevents old logs and links from silently acquiring a different
meaning while avoiding a fictitious trigger for behavior the current target
forbids.
