# E3095 — disjointness cannot be established for these operands

```ember,fails
from std.mem import assert_disjoint

fn main():
    a = 1
    b = 2
    r = assert_disjoint(ref a, ref b)
```

```text
error[E3095]: `ref i64` is not a view, so its disjointness cannot be established
```

## Why

`assert_disjoint` (and `assert_disjoint_or_panic`, `assert_disjoint_all`,
`assume_disjoint`) compares two views' address ranges: where each starts and
how many bytes it covers. A `Span` or `MutSpan` has both. A reference to a
single object has no range to compare, and two single objects are either the
same object or not: there is nothing for the comparison to establish.

## The fix

Compare views of the data, such as slices of two lists:

```ember,fixed
from std.mem import assert_disjoint

fn main():
    a: Array[int] = [1]
    b: Array[int] = [2]
    println(assert_disjoint(a[..], b[..]).is_ok())
```
