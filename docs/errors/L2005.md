# L2005 — `@noreload` function calls a reloadable one inside a loop

```toml
[build]
reload = "all"
```

```ember,fails
@noreload
fn total(xs: Array[int]) -> int:
    sum = 0
    for x in xs:
        sum += weigh(x)
    return sum

fn weigh(x: int) -> int:
    return x * 2

fn main():
    println(total([1, 2, 3]))
```

```text
warning[L2005]: `@noreload` function `total` calls reloadable `weigh` inside a loop
```

## Why

`@noreload` is for code kept out of hot reload for its speed: it is called directly and may be
inlined. A reloadable function is reached through its thunk, one load and one indirect jump that no
compiler can inline away. Calling one from inside a `@noreload` loop pays that on every turn, in the
code that was meant not to.

## The fix

Mark the callee `@noreload` too, so the loop calls it directly (a change to it then needs a
restart), or move the loop into a reloadable function.

```toml
[build]
reload = "all"
```

```ember,fixed
@noreload
fn total(xs: Array[int]) -> int:
    sum = 0
    for x in xs:
        sum += weigh(x)
    return sum

@noreload
fn weigh(x: int) -> int:
    return x * 2

fn main():
    println(total([1, 2, 3]))
```
