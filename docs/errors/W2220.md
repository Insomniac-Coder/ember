# W2220 — instantiation ceiling exceeded

```toml
[build]
max_instantiations = 2
```

```ember,fails
fn pick[T](a: T, b: T) -> T:
    return b

fn main():
    println(pick(1, 2), pick(1.5, 2.5), pick("a", "b"))
```

```text
warning[W2220]: `pick` has 3 instances, more than `max_instantiations = 2`
```

## Why

Each set of type arguments a generic is used with is a copy of its body in the program. The
manifest's ceiling says how many copies of one generic the package means to have; past it, the
warning names the generic and its newest instances so the growth can be seen where it starts.

## The fix

Raise the ceiling if the instances are wanted, or use the generic with fewer types (convert the
arguments to one type, or take an interface value where speed allows).

```toml
[build]
max_instantiations = 4
```

```ember,fixed
fn pick[T](a: T, b: T) -> T:
    return b

fn main():
    println(pick(1, 2), pick(1.5, 2.5), pick("a", "b"))
```
