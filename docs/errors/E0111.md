# E0111 — `ref` of an expression that is not a place

```ember,fails
fn five() -> int:
    return 5

fn main():
    r = ref five()
    println(r)
```

```text
error[E0111]: only a place can be borrowed
```

## Why

`ref e` and `ref mut e` borrow the place `e` names (`[GRM-36]`): a local, a
field, an element or a dereferenced reference. A call's result, an arithmetic
result or a literal is a value with no place of its own, so there is nothing
for the reference to point at once the expression is done.

## The fix

Bind the value to a local first, then borrow the local:

```ember,fixed
fn five() -> int:
    return 5

fn main():
    value = five()
    r = ref value
    println(r)
```
