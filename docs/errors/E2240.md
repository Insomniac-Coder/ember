# E2240 — `/` on two integers

```ember,fails
fn main():
    total = 17
    count = 5
    println(total / count)
```

```text
error[E2240]: `/` on two integers
```

## Why

In Ember, as in Python 3, `/` is true division: it applies to floats and
produces a float. Two integer operands have no true quotient in their own
type, and C's truncating division is a different operation that rounds
negative quotients toward zero. Rather than choose one silently, the compiler
asks which one is meant.

## The fix

Write `//` for floor division, which rounds toward negative infinity as
Python's does (`-7 // 2 == -4`):

```ember,fixed
fn main():
    total = 17
    count = 5
    println(total // count)
```

Or convert both operands to `float` for a float result:
`total as float / count as float`.
C's truncating quotient is `total.div_trunc(count)`.
