# E0109 — `owns` where the place already hands the value over

```ember,fails
struct Mesh:
    points: Array[float]

fn main():
    a = Mesh(points=[2.0])
    b = owns a
    println(len(b.points))
```

```text
error[E0109]: `b = a` already hands `a` over; remove `owns`
```

## Why

`owns` is written where it changes what happens: on a value made on the line for a place that owns it alone, or before an argument for an `owns` parameter. In `b = a` the `=` already hands the value over, so the word would say nothing and a reader would look for a difference that is not there (`[GRM-15]`).

## The fix

Remove `owns`:

```ember,fixed
struct Mesh:
    points: Array[float]

fn main():
    a = Mesh(points=[2.0])
    b = a
    println(len(b.points))
```
