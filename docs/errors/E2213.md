# E2213 — invalid `in` clause on a type alias

```ember,fails
type Bad[T] = T in 0 ..= 1

fn main():
    println(1)
```

```text
error[E2213]: a range type may not be generic
 --> page.em:1:6
  |
1 | type Bad[T] = T in 0 ..= 1
  |      ^^^^^^^^^^^^^^^^^^^^^
  |
  = help: a range is over one concrete representation; declare one `type` per representation
```

## Why

A range type is a nominal numeric type over one concrete representation (`[RNG-1]`, `[GRM-8d]`), so an alias that
carries generic parameters, or whose representation is not a number, cannot carry a range.

## The fix

Name the concrete representation:

```ember,fixed
type Bit = i32 in 0 ..= 1

fn main():
    println(1)
```
