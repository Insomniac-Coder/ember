# E2108 — `owns this` on `init`

```ember,fails
struct A:
    x: int

    fn init(x: int) owns this:
        this.x = x

fn main():
    println(A(1).x)
```

```text
error[E2108]: `init` builds the object, so it cannot take it over; write `fn init(x: int):`
 --> page.em:4:21
  |
4 |     fn init(x: int) owns this:
  |                     ^^^^^^^^^
  |
```

## Why

`init` builds the object: there is no object before it runs for it to take over.

## The fix

Remove `owns this`:

```ember,fixed
struct A:
    x: int

    fn init(x: int):
        this.x = x

fn main():
    println(A(1).x)
```
