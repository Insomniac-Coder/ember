# E2221 — borrow held across a `yield`

```ember,fails
gen fn items() -> Generator[int]:
    xs = [1, 2, 3]
    for x in xs:
        yield x

fn main():
    for x in items():
        println(x)
```

```text
error[E2221]: a borrow of `xs`, a local of this generator, is held across this `yield`
 = help: iterate the collection `owned` (`for x in owned xs:`), or by index; borrows of the generator's parameters may be held
```

## Why

A suspended generator is a value: its frame holds the locals that live across a
`yield`, and the caller may move it, keep it in a list or return it before
resuming it (`[CORO-5]`). A reference into one of those locals would then point
where the local used to be. Iterating a local list borrows it for the whole
loop, so a `yield` inside the loop would carry that borrow across the
suspension. References that came in as parameters point into the caller's
memory, which does not move with the frame, and may be held (`[CORO-6]`).

## The fix

Iterate the list `owned`, so the loop holds the elements rather than a borrow
of the list — or iterate by index:

```ember,fixed
gen fn items() -> Generator[int]:
    xs = [1, 2, 3]
    for x in owned xs:
        yield x

fn main():
    for x in items():
        println(x)
```
