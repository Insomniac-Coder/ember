# E3060 — a view used after what it points into was ended

```ember,fails
fn dangling() -> ref i32:
    local: i32 = 42
    return ref local

fn main():
    println(dangling())
```

```text
error[E3060]: `local` does not live long enough
 --> page.em:3:12
  |
2 |     local: i32 = 42
  |     --------------- `local` is a local, so its storage ends with the frame
3 |     return ref local
  |            ^^^^^^^^^ the borrow is still live when the function returns
  |            --------- `local` is borrowed here
  |
  = help: return an owned value, take the destination as a `ref mut` parameter, or borrow something the caller owns
  = note: a returned reference must derive from a parameter (LT-1)
```

## Why

A view is safe only while the place it points into is alive (`[BRW-9]`, `[LT-1]`). `local` ends when `dangling`
returns, so a view of it handed back would point into a frame that no longer exists. The compiler follows each
view to the place it points into and refuses a use after that place was ended, handed over, replaced or reshaped.

## The fix

Return the value, which is a copy of its own, instead of a view of the local:

```ember,fixed
fn dangling() -> i32:
    local: i32 = 42
    return local

fn main():
    println(dangling())
```
