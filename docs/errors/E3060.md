# E3060 — a view used after what it points into was ended

```ember,fails
fn main():
    s = String("abc")
    v = ref s
    t = s
    println(v, t)
```

```text
error[E3060]: `s` was handed over, and a view of it is still used here
```

## Why

A view is safe only while the place it points into is alive and in place (`[BRW-17]`, `[OWN-3]`). `t = s` hands
the text over to `t`, so `v` would point into a place that no longer holds it. The compiler follows each view to
the place it points into and refuses a use after that place was ended, handed over, replaced or reshaped.

## The fix

Use the view before the hand-over:

```ember,fixed
fn main():
    s = String("abc")
    v = ref s
    println(v)
    t = s
    println(t)
```

A view returned out of the function that made what it points into is `E3063`.
