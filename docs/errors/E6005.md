# E6005 — a compile-time expression names a run-time local

```ember,fails
fn main():
    count = 5
    println(comptime(count * 2))
```

```text
error[E6005]: `count` is a run-time local, which compile time cannot read
```

## Why

`comptime(e)` is worked out while the program compiles, before any of its
locals exist. A local has a value only when the program runs, and may have a
different one each time, so compile time has nothing to read for it. What a
compile-time expression may name is what compile time knows: constants,
generic parameters, and statics initialised at compile time.

## The fix

Compute the value from a constant, or leave the expression to run time:

```ember,fixed
const COUNT: int = 5

fn main():
    println(comptime(COUNT * 2))
    count = 5
    println(count * 2)
```
