# E9014 — the C toolchain cannot emit stack probes

```ember,fails,toolchain
fn fill() -> int:
    buf: [u8; 100000] = [0; 100000]
    buf[0] = 1
    return buf[0] as int

fn main():
    println(fill())
```

```text
error[E9014]: `gcc` cannot emit stack probes for a frame larger than a guard page: it does not take `-fstack-clash-protection` [RT-12]
  = help: use Clang 11 or GCC 8 or later
```

## Why

The backend compiles every target with stack probes, so a frame larger than a page touches each page in order
and a stack overflow lands on the guard page instead of beyond it (`[RT-12]`). A Clang or GCC that does not
take `-fstack-clash-protection` cannot probe, so the build is refused rather than made without the protection.

## The fix

Build with Clang 11 or GCC 8 or later (MSVC and clang-cl probe by default); the program itself is valid and needs
no change:

```ember,fixed
fn fill() -> int:
    buf: [u8; 100000] = [0; 100000]
    buf[0] = 1
    return buf[0] as int

fn main():
    println(fill())
```
