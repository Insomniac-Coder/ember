# E5015 — an exported signature reaches an Ember-owned value

```ember,fails
pub extern "C" fn read_text(text: *String) -> i32:
    return 0

fn main():
    pass
```

```text
error[E5015]: exported parameter `text` reaches an owning Ember value
```

## Why

An exported C function can be called by code that does not know Ember's
ownership and drop rules. A raw pointer changes the argument's carrier, but
it does not make the `String` behind it a C value. The same restriction applies
to a record containing an Ember owner, a type with drop glue, and a callback
signature that reaches one through its parameters or result.

## The fix

Keep the owner on the Ember side. Pass C-compatible data across the boundary
and state its lifetime in the surrounding API:

```ember,fixed
pub extern "C" fn byte_count(data: *u8, len: usize) -> usize:
    return len

fn main():
    println(byte_count(null[*u8](), 0))
```
