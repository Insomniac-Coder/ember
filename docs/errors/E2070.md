# E2070 — ambiguous interface method

```ember,fails
interface Walker:
    fn go() -> int

interface Swimmer:
    fn go() -> int

struct Duck:
    n: int

extend Duck implements Walker:
    fn go() -> int:
        return 1

extend Duck implements Swimmer:
    fn go() -> int:
        return 2

fn main():
    d = Duck(n=0)
    println(d.go())
```

```text
error[E2070]: `go` is offered by both `Swimmer` and `Walker`
  --> page.em:20:15
   |
20 |     println(d.go())
   |               ^^
   |
```

## Why

A method is found through every implementation visible in the program (`[TYP-24]`), so a type that
implements two interfaces which both supply a method named `go` has two candidates for `d.go()`. Picking
one by declaration order would make a program change meaning when an unrelated `extend` is added or
moved; the compiler asks the author to say which one is meant instead.

## The fix

Name the interface in the call, `I.m(recv, …)`:

```ember,fixed
interface Walker:
    fn go() -> int

interface Swimmer:
    fn go() -> int

struct Duck:
    n: int

extend Duck implements Walker:
    fn go() -> int:
        return 1

extend Duck implements Swimmer:
    fn go() -> int:
        return 2

fn main():
    d = Duck(n=0)
    println(Walker.go(d))
```
