# E7017 — `thread_shared` of a value made otherwise

```ember,fails
class Names:
    n: int = 0

fn main():
    names = Names()
    _shared = thread_shared names
```

```text
error[E7017]: `names` was not made `thread_shared` (made on line 5), so its owners are counted on one thread; to share it between threads, create it shared: `names = thread_shared ...`
```

## Why

A value's owners are counted one way from the moment it is made: with plain adds on one thread, or in
the counts several threads may use. A value cannot change over later, and `shares` of a `thread_shared`
value is refused for the same reason: a plain count would race the other threads.

## The fix

Make the value shared where it is created:

```ember,fixed
class Names:
    n: int = 0

fn main():
    names = thread_shared Names()
    _other = thread_shared names
```
