# E0003 — an inconsistent dedent

```ember,fails
fn main():
    if true:
        println(1)
      println(2)
```

```text
error[E0003]: inconsistent dedent
```

## Why

Blocks are made by indentation, so a line that returns to a depth no open block has leaves its block unknown: `println(2)` could belong to the `if` or to `main`. The lexer pops its indentation stack until a level matches (`[LEX-5]`), and a line that matches none is refused rather than guessed.

## The fix

Indent the line to the depth of the block it belongs to, here the `if` body or `main`'s:

```ember,fixed
fn main():
    if true:
        println(1)
    println(2)
```
