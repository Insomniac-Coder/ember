# E0118 — a first line whose parts are out of order

```ember,fails
struct Counter:
    n: int = 0

    fn finish() -> u64 owns this:
        return 1

fn main():
    c = Counter()
    println(c.finish())
```

```text
error[E0118]: a function's first line gives its parts in this order: the parameters, `owns this`, `->` and the result type, `from` and what the result points into
  = help: write `fn finish() owns this -> u64:`
```

## Why

A function's first line is read in one order, so every first line looks alike and each part is
found where a reader expects it: the parameters, `owns this`, `->` and the result type, then `from`
and what the result points into.

## The fix

```ember,fixed
struct Counter:
    n: int = 0

    fn finish() owns this -> u64:
        return 1

fn main():
    c = Counter()
    println(c.finish())
```
