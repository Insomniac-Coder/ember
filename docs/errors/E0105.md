# E0105 — a semicolon as a statement separator

```ember,fails
fn main():
    a = 1; b = 2
    println(a + b)
```

```text
error[E0105]: `;` is not a statement separator
```

## Why

A line carries one statement, so that the indentation and the line structure show the program's structure and a statement is never hidden at the end of a line (`[GRM-18]`). `;` appears only inside `[T; N]` and `[v; N]`.

## The fix

Put each statement on its own line:

```ember,fixed
fn main():
    a = 1
    b = 2
    println(a + b)
```
