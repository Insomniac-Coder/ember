# L3002 — borrow held longer than necessary

```ember,fails
import std.sync

fn report(n: int) -> int:
    return n * 2

fn main():
    m = sync.Mutex(0)
    with g = m.lock():
        g += 1
        println(report(3))
```

```text
warning[L3002]: `g` is still held here, after its last use
```

## Why

A lock guard keeps its lock until it ends, which `with` places at the end of the block. Everything
after the guard's last use still runs under the lock: other threads that want it wait for work that
does not need it, and the longer a lock is held, the more of them line up behind it.

## The fix

End the block at the guard's last use, and run the rest after it.

```ember,fixed
import std.sync

fn report(n: int) -> int:
    return n * 2

fn main():
    m = sync.Mutex(0)
    with g = m.lock():
        g += 1
    println(report(3))
```
