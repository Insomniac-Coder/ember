# E1040 — retired: glob imports

`E1040` is no longer emitted. It once refused a glob import (`from m import *`) outside the modules that
were allowed to have one.

Glob imports are allowed from any module (`[MOD-8]`), so the refusal went, and the number is not reused.

## Why

The rule lets a glob import come from any module, so a refusal by module kind has nothing to refuse.
