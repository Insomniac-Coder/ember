# E0117 — a parameter's mode written in its type

```ember,fails
fn grow(c: ref mut int):
    c += 1

fn main():
    k = 1
    grow(ref mut k)
    println(k)
```

```text
error[E0117]: the mode goes on the name, not in its type
  = help: write `fn grow(ref mut c: int):`
```

## Why

How a parameter is passed is its word, written before its name: `ref mut c: int` is the caller's
`int` itself, which the function may change. Written in the type, `ref mut` would describe a value
the parameter holds rather than how it is passed, so each is said in one place: the word on the
name, the type after the colon. (A foreign function's declaration writes the pointer C takes as its
type, `data: ref mut [i32; 2]`, which its contract describes, and is not this.)

## The fix

```ember,fixed
fn grow(ref mut c: int):
    c += 1

fn main():
    k = 1
    grow(ref mut k)
    println(k)
```
