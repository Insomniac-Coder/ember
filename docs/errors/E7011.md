# E7011 — a parallel loop has a loop-carried dependency

```ember,fails
fn main():
    values = [1, 2, 3, 4, 5]
    xs = values.as_mut_span()
    @parallel
    for i in 0..4:
        xs[i] = xs[i + 1]
    println(values)
```

```text
error[E7011]: parallel loop has a loop-carried dependency on `xs`
```

## Why

Every access to a place a `@parallel` loop writes, reads included, must be at
one offset from its index. Here iteration `i` reads `xs[i + 1]`, which
iteration `i + 1` writes; run at once on two threads, the read may see the old
value or the new one.

## The fix

Read from a copy and write to another place, so the place written is reached
only at `i`; or split it into two `@parallel` loops, or run it serially:

```ember,fixed
fn main():
    values = [1, 2, 3, 4, 5]
    source = values.clone()
    xs = values.as_mut_span()
    @parallel
    for i in 0..4:
        xs[i] = source[i + 1]
    println(values)
```
