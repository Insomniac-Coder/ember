# L4003 — large `Array[int]`/`Array[float]` in a hot loop whose values fit 32 bits

```ember,fails
fn main():
    n = 10000
    codes: Array[int] = []
    for i in 0..n:
        codes.push(i % 1000)
    total = 0
    for i in 0..n:
        total += codes[i]
    println(total)
```

```text
warning[L4003]: `codes` holds more than 64 KiB of `i64` values that all fit in `i32`, and this hot loop indexes it
```

## Why

A loop over a large list is limited by how fast memory delivers it, not by the arithmetic. An `int`
or a `float` takes eight bytes; when every value the list holds fits in four (here every one is below
1000), half of every cache line the loop waits for is zeros. A list of `i32` (or `f32`) carries the
same values in half the memory, so the loop waits half as long.

## The fix

Store the values as `i32` (`u32`, `f32`) and widen each one as it is read.

```ember,fixed
fn main():
    n = 10000
    codes: Array[i32] = []
    for i in 0..n:
        codes.push((i % 1000) as i32)
    total = 0
    for i in 0..n:
        total += codes[i] as int
    println(total)
```
