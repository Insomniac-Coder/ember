# E3011 — moving out of an element

```ember,fails
fn main():
    names = ["ann".to_string(), "bob".to_string()]
    first = names[0]
    println(first)
```

```text
error[E3011]: cannot move out of an element
```

## Why

An element of an array, an `Array`, a `Span` or an `SoA` column stays in its container, and the
container drops every element it holds. Moving one out would leave a value the container still
destroys, so a `String` there would be freed twice.

## The fix

Clone it, or take it out and leave something in its place:

```ember,fixed
fn main():
    names = ["ann".to_string(), "bob".to_string()]
    first = names[0].clone()
    last = names.pop()
    println(first, last)
```

`mem.take`, `mem.replace` and `swap` leave a value behind; `pop` and `remove` shorten the
container.
