# E3070 — `drop` called explicitly

```ember,fails
struct R:
    pub v: Array[i32]

    fn drop(mut self):
        print(self.v[0])

fn main():
    a: Array[i32] = Array[i32]()
    a.push(1)
    r = R(a)
    r.drop()
    print(2)
```

```text
error[E3070]: `R`'s `drop` may not be called explicitly
  --> page.em:12:7
   |
12 |     r.drop()
   |       ^^^^ this would run the destructor a second time
   |
   = help: `mem.drop(owned x)` ends the value's life early; the destructor then runs once, here
   = note: `drop` is invoked exactly once per value, at the end of its life [DRP-1]
```

## Why

The word to read carefully in `[DRP-1]` is **exactly**: "`fn drop(mut self)` is
invoked exactly once per value at the end of its life."

An explicit call does not *replace* the one at the end of the life. It adds to
it. After `r.drop()` returns, `r` is still a live local — nothing about the call
told the compiler otherwise — so the scope-end drop runs too, and the destructor
runs twice.

For a type that owns nothing that is merely a duplicated `print`. For the type
above it is a **double free**: the first run releases the buffer, the second
reads `self.v[0]` from released memory and releases it again. No `unsafe`
appears anywhere in the program.

This is why `drop` is not an ordinary method even though it is written like one.
Every other method leaves the value where it was; this one ends it, and a
mechanism that ends something has to be the only one doing so.

## The fix

If you want the value gone early, say that — `mem.drop` takes it by `owned`, so
the value is moved into it and its life genuinely ends there. The destructor
runs once, at the point you asked for, and the scope-end drop does not happen
because there is nothing left to drop.

```ember,fixed
struct R:
    pub v: Array[i32]

    fn drop(mut self):
        print(self.v[0])

fn early(owned r: R):
    # `r` is this function's now, so its life ends when this returns —
    # which is the same effect, expressed as an ownership move.
    print(0)

fn main():
    a: Array[i32] = Array[i32]()
    a.push(1)
    r = R(a)
    early(r)
    # `r` was moved, so nothing is dropped here.
    print(2)
```

Two other shapes are usually what was really wanted:

**Put the cleanup somewhere it can be called.** If the thing you want early is a
*flush*, or a *close*, or a *release of one resource*, that is an ordinary
method with an ordinary name, and `drop` calls it too.

**Shorten the scope.** A value declared inside a block is dropped at the end of
that block, so an inner block is often the whole answer and costs nothing.
