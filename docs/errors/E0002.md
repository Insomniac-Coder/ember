# E0002 — a tab in indentation

```ember,fails
fn main():
	println(1)
```

```text
error[E0002]: tab used for indentation
```

## Why

Python 2 let a tab stand for some number of spaces, and editors disagree on how many; the same file then shows two different block structures. Ember fixes the question by allowing spaces only, so the indentation a reader sees is the indentation the compiler reads (`[LEX-4]`).

## The fix

Replace the tab with spaces (the compiler's fix-it uses four):

```ember,fixed
fn main():
    println(1)
```
