# E2072 — a Python method name Ember spells otherwise

```ember,fails
fn main():
    names = ["ann"]
    names.append("bob")
```

```text
error[E2072]: no method `append` on `Array[str]`
```

## Why

Ember has one naming convention: `snake_case` words, the same name in every type. Where Python's
name for a method differs (`append`, `strip`, `startswith`, `upper`, `splitlines`), there is no
second name; the help says Ember's.

## The fix

Use Ember's name:

```ember,fixed
fn main():
    names = ["ann"]
    names.push("bob")
    println(names)
```
