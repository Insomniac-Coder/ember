# E0900 — construct not implemented by this compiler

```ember,fails
fn next() -> int:
    return 5

fn main():
    println(0 < next() < 10)
```

```text
error[E0900]: a computed operand in the middle of a comparison chain is not implemented yet
```

## Why

The specification defines the construct, and this compiler does not implement
it yet. It is rejected by name rather than accepted with a meaning the
specification does not give it, or passed on to fail later. The message names
the construct; the help, where there is one, gives a form that is implemented.

## The fix

Use the form the help names. Here, bind the computed operand first:

```ember,fixed
fn next() -> int:
    return 5

fn main():
    n = next()
    println(0 < n < 10)
```
