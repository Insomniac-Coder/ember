# E0101 — an unclosed delimiter or literal

```ember,fails
fn main():
    s = "never closed
    println(1)
```

```text
error[E0101]: unterminated string
```

## Why

A string, bracket or f-string hole left open would swallow the rest of the file into one token, and the errors that followed would point far from the mistake. The lexer ends it at the line and says what was left open (`[LEX-6]`, `[LEX-26]`).

## The fix

Close the string:

```ember,fixed
fn main():
    s = "closed"
    println(s)
```

* `[LEX-26]` — a string left unclosed is `E0101`.
