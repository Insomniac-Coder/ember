# E2172 — cannot index with a type

```ember,fails
fn main():
    xs: Array[i32] = Array[i32]()
    n: i32 = xs[ref i32]
    println(n)
```

```text
error[E2172]: cannot index with a type
 --> page.em:3:17
  |
3 |     n: i32 = xs[ref i32]
  |                 ^^^^^^^
  |
```

## Why

Inside `[ ]` a type is read as a type on the tokens that cannot begin an expression (`[GRM-8a]`), so
`xs[ref i32]` parses; `[GRM-8b]` then reports it for what it is, an index whose argument is a type, rather
than a type mismatch about the whole expression. An index is a value.

## The fix

Index with an integer:

```ember,fixed
fn main():
    xs: Array[i32] = Array[i32]()
    xs.push(owns 7)
    n: i32 = xs[0]
    println(n)
```
