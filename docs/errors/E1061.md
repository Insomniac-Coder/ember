# E1061 — no item of that name in the module

```ember,fails
from std.math import square_root

fn main():
    println(square_root(9.0))
```

```text
error[E1061]: module 'std.math' has no item named `square_root`
```

## Why

`from m import x` binds `x` from module `m`. When `m` exists but declares nothing named `x`, the
import is wrong at the import, and it is reported there rather than at the first use of `x`
(`[MOD-3]`). An item that exists but is private to its module is `E1052` instead.

## The fix

Import an item the module declares:

```ember,fixed
from std.math import sqrt

fn main():
    println(sqrt(9.0))
```
