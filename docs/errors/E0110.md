# E0110 — a function declared without a body

```ember,fails
struct Point:
    x: int

    fn length(self) -> int

fn main():
    println(Point(3).x)
```

```text
error[E0110]: `length` is declared without a body
```

## Why

A function with no body says what may be called without saying what the call
does. That is meaningful in three places only (`[GRM-33]`): an `interface`,
whose implementations give the bodies; an `extern` block, whose functions are
defined in C; and a `virtual` method of an `abstract class`, which every
concrete subclass overrides. Anywhere else nothing could ever supply the body,
and accepting the declaration would only move the mistake to the first call
(`[PHIL-12]`).

## The fix

Add `:` and a body:

```ember,fixed
struct Point:
    x: int

    fn length(self) -> int:
        return self.x

fn main():
    println(Point(3).length())
```

Or, if the declaration was meant as a contract, put it in an `interface`.
