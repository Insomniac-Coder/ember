# W0001 — retired: a dangling doc comment

`W0001` is no longer emitted. It warned about a doc comment (`##`) with no item after it.

Since 0.9.20 a dangling doc comment is discarded in silence: the owner ruled that a comment that documents nothing costs nothing (`[LEX-11]`, the registry's retired codes).
