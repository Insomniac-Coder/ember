# E4040 — a `@nopanic(explicit)` function reaches a panic

```ember,fails
@nopanic(explicit)
fn f(n: int) -> int:
    assert(n > 0)
    return n

fn main():
    println(f(1))
```

```text
error[E4040]: `@nopanic(explicit)` function `f` reaches a panic
  = note: f -> `assert`
  = note: `@nopanic(explicit)` forbids only the panics the program writes and allocation failure; arithmetic, bounds, aliasing and stale-handle checks are allowed under it (EFF-16)
```

## Why

`@nopanic(explicit)` promises that the function contains no panic its author wrote — `panic`,
`assert`, `unwrap`, `expect`, `as!` — and no allocation, whose failure panics. It does not promise
that the function cannot stop: an overflow, an index out of range or a stale handle still panics,
and those checks are allowed under it. That is why the attribute carries `(explicit)`: so no reader
takes it to mean "cannot abort".

## The fix

```ember,fixed
@nopanic(explicit)
fn f(n: int) -> int:
    if n > 0:
        return n
    return 0

fn main():
    println(f(1))
```

Handle the case instead of asserting it, or return an `Option` or a `Result`.
