# E5050 — a grade claimed with no evidence, where evidence is required

```ember,fails
unsafe overlay c "zlib.h":  # SAFETY(ffi): each entry matches its declaration in the header
    @grade(instrumented)
    @ffi(effects=[FFI])
    fn zlibVersion() -> borrowed nul_terminated from(static)

fn main():
    pass
```

```text
error[E5050]: `instrumented` is claimed with no evidence: the fact stays asserted
 --> page.em:2:5
  |
2 |     @grade(instrumented)
  |     ^^^^^^^^^^^^^^^^^^^^
  |
  = note: `instrumented` needs a run of `ember test --instrument-ffi` that observed it, recorded under the manifest's `[ffi] evidence` (`.ember/ffi-evidence`) [TCB-1]
  = note: writing a grade never raises it [TCB-2]
  = note: a claimed grade needs its evidence under `--require-evidence` [TCB-1]
```

This page's program is checked with `ember check --require-evidence`; without the flag the same
claim is the warning `W5050`.

## Why

A fact about foreign code is graded by what stands behind it: asserted, instrumented, checked or
proven. An ordinary build lets a claimed grade stand unbacked and says so (`W5050`): the fact is
treated as asserted, and the trusted-base report shows it as such. A release, or a review of the
trusted base, wants more: that every grade the overlays claim is the grade the evidence gives.
`ember build --require-evidence` and `ember tcb --require` make each unbacked or stale claim an
error, so a build cannot ship on a grade nobody earned. Evidence goes stale when what it was
gathered from changes — the test binary, the toolchain, the declaration, the header or the
overlay — so a claim that was backed yesterday can fail today, which is the point.

## The fix

Produce the evidence the grade names (`ember test --instrument-ffi` records it under the
manifest's `[ffi] evidence`), or claim no more than asserted:

```ember,fixed
unsafe overlay c "zlib.h":  # SAFETY(ffi): each entry matches its declaration in the header
    @grade(asserted)
    @ffi(effects=[FFI])
    fn zlibVersion() -> borrowed nul_terminated from(static)

fn main():
    pass
```
