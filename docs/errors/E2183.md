# E2183 — `main` has none of the forms `[FN-8]` allows

```ember,fails
fn main(count: int):
    println(count)
```

```text
error[E2183]: `main` has none of the forms `[FN-8]` allows: it takes `count: i64`
```

## Why

The program starts at `main`, and nothing in the program calls it, so its
parameters and its result have to be ones the start of a program can give and
take. `main` takes nothing, or the command line as one `Array[String]` (any
name, any mode), and returns nothing, or a `Result[void, E]` whose `Err` is
printed as `error: <message>` before the process exits with status 1. Another
parameter, a second one, another return type or type parameters have no
meaning there.

## The fix

Read numbers from the command line, and report a failure by returning `Err`:

```ember,fixed
fn main(args: Array[String]) -> Result[void, String]:
    if args.len() < 2:
        return Err("give a count".to_string())
    count = args[1].parse[int]().unwrap_or(0)
    println(count)
```
