# W1002 — a binding spelled like another enum's variant

```ember,fails
enum Color:
    Red
    Green

enum Light:
    Off
    On(int)

fn show(l: Light):
    match l:
        Red:
            println("off or on")

fn main():
    show(Light.Off)
```

```text
warning[W1002]: `Red` binds a new name, which matches any value
```

## Why

In pattern position a name is a variant of the matched enum, or a `const`, if
one of that name is in scope; otherwise it binds a new name, which matches
anything (`[GRM-12]`). `Red` is not a variant of `Light`, so the arm above
binds `Red` and runs for every light. A reader, seeing `Color.Red` in scope,
takes it for that variant.

## The fix

Write the variant you mean in full, or give the binding a name that is no
variant's:

```ember,fixed
enum Color:
    Red
    Green

enum Light:
    Off
    On(int)

fn show(l: Light):
    match l:
        any_light:
            println("off or on")

fn main():
    show(Light.Off)
```
