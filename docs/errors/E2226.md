# E2226 — `in` on a type that does not implement `Contains`

```ember,fails
fn main():
    x = 5
    println(1 in x)
```

```text
error[E2226]: `i64` does not implement `Contains`
```

## Why

`x in c` asks `c` whether it contains `x`, and only a type that knows how to
answer can be asked. An `Array`, a view and a fixed array answer by scanning
their elements; a string answers for a `str` or a `char` needle; a range
written in place (`x in 0..10`) answers with two comparisons. A number, a
struct or a class has no elements to search, so the question has no meaning,
and the compiler never makes up an answer.

## The fix

Ask a container, or write the test you mean:

```ember,fixed
fn main():
    xs = [5, 6]
    println(1 in xs)
```
