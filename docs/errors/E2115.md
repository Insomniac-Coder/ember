# E2115 — `static fn` is a function of a type body

```ember,fails
static fn double(x: int) -> int:
    return x * 2

fn main():
    println(double(4))
```

```text
error[E2115]: `static fn` is a function of a type body
  = help: remove `static`: a function outside a type body has no object
```

## Why

Inside a type body a function is a method, and its object is `this`; `static fn` writes one that
has no object, called on the type (`Counter.starting_at(5)`). Outside a type body no function has
an object, so `static` says nothing there, and a word that says nothing is refused rather than
ignored.

## The fix

```ember,fixed
fn double(x: int) -> int:
    return x * 2

fn main():
    println(double(4))
```
