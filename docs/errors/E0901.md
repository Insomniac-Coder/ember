# E0901 — construct this specification leaves unspecified

```ember,fails
@packed
@align(8)
struct Header:
    tag: u8
    length: u32

fn main():
    println(size_of[Header]())
```

```text
error[E0901]: `@align` beside `@packed` is not specified
```

## Why

Where the specification says nothing about what a construct means, or two of
its rules say different things, the compiler does not pick an answer by analogy
with another language (`[PHIL-12]`): it rejects the construct, and the question
goes to the language's owner. Here `@packed` leaves no padding, while
`@align(8)` makes the size a multiple of eight, which takes padding: the
specification does not say which of the two wins (`[LAY-2]`).

## The fix

Write only what the specification defines. Here, keep one of the two
attributes:

```ember,fixed
@packed
struct Header:
    tag: u8
    length: u32

fn main():
    println(size_of[Header]())
```
