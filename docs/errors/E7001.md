# E7001 — retired: a `@sync` class

`E7001` is no longer emitted. It reported a problem with a class marked `@sync`, and `@sync` is gone.

A value shared between threads is now `thread_shared`, and its changing fields are `guarded by` a lock or are `Atomic`. Writing `@sync` is `E0104`, and a type that cannot be shared is `E7015`.
