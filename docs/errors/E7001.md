# E7001 — a `@sync` class has a non-shareable field or base

```ember,fails
class Local:
    value: int = 0

@sync
class Shared:
    item: Local

    fn init(mut self, item: Local):
        self.item = item
```

```text
error[E7001]: field `Shared.item` has type `Local`, which is not Send or Sync
```

## Why

Handles of a `@sync` class may cross threads. Every field must be both `Send`
and `Sync`, including fields declared `let`: the final release may drop a field
on any thread, and all threads may read it. A base and its derived class must
also agree on `@sync`.

## The fix

Use shareable fields and declare the whole class hierarchy `@sync`, or leave
the class confined to one thread:

```ember,fixed
@sync
class Shared:
    value: int

    fn init(mut self, value: int):
        self.value = value
```
