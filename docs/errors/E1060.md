# E1060 — no module of that name

```ember,fails
import std.maths

fn main():
    println(maths.sqrt(9.0))
```

```text
error[E1060]: no module named 'std.maths'
 = help: the nearest modules: `std.math`, …
```

## Why

An import names a module by its path: the standard library's under `std`, or the package's own
under its source root (`[MOD-1]`). A path that names no module is reported at the import itself,
never later at the first use of a name it was meant to bring in, and never skipped in silence
(`[MOD-3]`, `[PHIL-12]`). The help lists the existing module paths nearest the one written, which
is usually a misspelling.

A standard module the specification describes but this compiler has not written yet is `E0900`
instead: the module exists in the language, not here.

## The fix

Name a module that exists:

```ember,fixed
import std.math

fn main():
    println(math.sqrt(9.0))
```
