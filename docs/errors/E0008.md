# E0008 — unterminated character literal

```ember,fails
fn main():
    c = 'a
    println(c)
```

```text
error[E0008]: unterminated character literal
```

## Why

A `'` begins a character literal and nothing else (`[LEX-22]`), so everything
up to the closing `'` on the same line is the character. Without one there is
no literal to read. Ember has no lifetime syntax, so `'a` never names a region.

## The fix

Close the literal:

```ember,fixed
fn main():
    c = 'a'
    println(c)
```
