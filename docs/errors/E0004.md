# E0004 — an expected indented block

```ember,fails
fn main():
    if true:
    println(1)
```

```text
error[E0004]: expected an indented block
```

## Why

A line ending in `:` opens a block, and the block is what is indented under it (`[LEX-9]`). A `:` followed by a line at the same depth would leave the `if` with no body, which is almost always a forgotten indent.

## The fix

Indent the body under the `:`:

```ember,fixed
fn main():
    if true:
        println(1)
```

## See also

* `[LEX-9]` — an indented block follows a line ending in `:`, unless the block is one simple statement on the same line.
