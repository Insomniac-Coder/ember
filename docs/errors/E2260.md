# E2260 — a `some` type outside a function's return type

```ember,fails
interface Shape:
    fn area(self) -> float

fn measure(s: some Shape) -> float:
    return s.area()
```

```text
error[E2260]: a `some` type is legal only in a function's return type
```

## Why

`some I` stands for one concrete type that a function's body chooses and its callers see only as
`I`. Only the function that returns the value can choose it, so the type can be written only in a
return type (or nested inside one). A parameter, a field or a local has no body choosing its type.

## The fix

Take a type parameter bounded by the interface: each call monomorphises the function for the type
it is given, which is what `some` would have meant in that position.

```ember,fixed
interface Shape:
    fn area(self) -> float

fn measure[T: Shape](s: T) -> float:
    return s.area()
```
