# L3014 — retired: return region is the intersection of parameters

`L3014` is no longer emitted, and `l3014` in a manifest's `[lints]` is an unknown lint (`E9010`). It
warned, when a package turned it on, that a returned view under `[LT-1]` rule 3 points into more than
one parameter, and asked for `@borrows` to say which.

Since 0.9.15, `@borrows` is gone (`[ATT-1]`) and a result points into every view argument it may come
from (`[LT-1]`, `[LT-22]`); where it should point into one, `from` says so after the result type:

```ember
fn pick(a: Span[i32], b: Span[i32]) -> Span[i32] from a:
    return a
```
