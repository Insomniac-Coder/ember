# E6010 — an operation compile time cannot run

```ember,fails
fn greeting() -> int:
    println("hello")
    return 1

const GREETING: int = greeting()

fn main():
    println(GREETING)
```

```text
error[E6010]: `GREETING` cannot run while compiling: it reaches console output
```

## Why

Compile-time evaluation runs the program's own functions, but only those whose
effects are `Alloc`, `Panic` and run-time checks. Its result is part of the
build, so it must be the same on every build of the same source: console and
file I/O, a foreign call, a thread, a lock, a clock, `unsafe` memory access
and the platform's own maths functions could each give another answer, or
reach outside the build. The diagnostic names the call chain to the operation.
The two inputs compile time does have, `comptime.read_file` (inside the
package directory) and `comptime.env`, are recorded as inputs of the build.

## The fix

Keep the work at compile time pure, and do the I/O at run time:

```ember,fixed
fn greeting() -> int:
    return 1

const GREETING: int = greeting()

fn main():
    println("hello")
    println(GREETING)
```
