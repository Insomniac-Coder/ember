# E2229 — class generator method takes `mut self` or holds an access across `yield`

```ember,fails
class Bag:
    items: Array[int] = []

    gen fn each(self) -> Generator[int]:
        for x in self.items:
            yield x

fn main():
    for x in Bag().each():
        println(x)
```

```text
error[E2229]: a borrow of a field of a class object is held across this `yield`
 = help: copy what is needed out of the field before the `yield`, or iterate by index
```

## Why

A class object is shared through its handles, and every access to one of its
fields is checked so that no two conflict (`[EXC-1]`). A generator method keeps
the object's handle in its frame, and between two of its steps any other code
may run and touch the object. A borrow of a field held across a `yield` would
be an access left open all that time, which nothing could check; so would the
write access a `mut self` method holds for its whole run (`[CORO-12]`). Each
access inside the body is therefore checked on its own, and none spans a
suspension.

## The fix

Read the field afresh at each step, by index:

```ember,fixed
class Bag:
    items: Array[int] = []

    gen fn each(self) -> Generator[int]:
        i = 0
        while i < self.items.len():
            yield self.items[i]
            i += 1

fn main():
    for x in Bag().each():
        println(x)
```
