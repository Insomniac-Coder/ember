# L5002 — conversion at the FFI boundary copies

```ember,fails
import std.ffi

unsafe extern "C":
    @ffi(param(text, borrowed, nul_terminated))
    safe fn strlen(text: cstr) -> usize

fn main():
    total: usize = 0
    for word in ["alpha", "beta"]:
        text = word.to_cstring().unwrap()
        total += strlen(text.as_cstr())
    println(total)
```

```text
warning[L5002]: `to_cstring` copies its argument for a foreign call
```

## Why

Ember text is not terminated by a zero byte and C text is, so text crosses to C only through a
conversion that copies it into a new buffer, and back through one that copies it out (`to_cstring`,
`to_wide`, `WideString.from_units`, `WideString.to_string`). Each is explicit in the source; the lint
points out where one stands at the boundary, so a copy repeated on every call is seen and made once.

## The fix

Convert once, and pass the converted value each time it crosses.

```ember,fixed
import std.ffi

unsafe extern "C":
    @ffi(param(text, borrowed, nul_terminated))
    safe fn strlen(text: cstr) -> usize

fn main():
    total: usize = 0
    for word in [c"alpha", c"beta"]:
        total += strlen(word)
    println(total)
```
