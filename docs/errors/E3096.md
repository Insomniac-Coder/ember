# E3096 — an arena is already scoped

```ember,fails
fn main():
    arena = Arena.with_capacity(32)
    scope = arena.scope()
    parent: ref mut i32 = arena.alloc(1)
    child: ref mut i32 = scope.alloc(2)
    println(parent + child)
```

```text
error[E3096]: `arena` is scoped here
 --> page.em:4:27
  |
3 |     scope = arena.scope()
  |             ------------- mutable borrow of `arena` starts here
4 |     parent: ref mut i32 = arena.alloc(1)
  |                           ^^^^^^^^^^^^^^ conflicting access here
5 |     child: ref mut i32 = scope.alloc(2)
6 |     println(parent + child)
  |                      ----- borrow later used here
  |
  = help: allocate from `scope` instead, or take this allocation before opening the scope
  = note: a ScopedArena holds its parent's mutable borrow for the scope's whole region (ARN-6)
```

## Why

`Arena.scope()` takes a mutable borrow of its parent. The returned
`ScopedArena` guard retains that borrow until its last use and rewinds the
parent to the captured mark when it is dropped. Accessing the parent while the
scope is live would bypass the scope's LIFO allocation boundary.

Nested scopes use the same rule: while a child scope is live, allocate through
that child rather than through any ancestor.

## The fix

Allocate through the active scope, or complete the scoped work before using
the parent again.

```ember,fixed
fn main():
    arena = Arena.with_capacity(32)
    scope = arena.scope()
    first: ref mut i32 = scope.alloc(1)
    second: ref mut i32 = scope.alloc(2)
    println(first + second)
```
