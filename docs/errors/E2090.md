# E2090 — non-exhaustive match

```ember,fails
enum Color:
    Red
    Green
    Blue

fn weight(c: Color) -> int:
    match c:
        Color.Red:
            return 1
        Color.Green:
            return 2
    return 0

fn main():
    println(weight(Color.Blue))
```

```text
error[E2090]: `match` on `Color` does not cover every value
 --> page.em:7:5
  |
7 |     match c:
  |     ^^^^^^^^ `Color.Blue` not covered
  |
  = note: add the missing arms, or `_` as a catch-all [ENM-2]
```

## Why

A `match` on an enum must cover every variant (`[ENM-2]`), so that adding a variant to the enum later makes
every `match` that forgot it fail to compile instead of falling through silently at run time. The
diagnostic lists the variants that are missing.

## The fix

Write an arm for each missing variant, or `_` for all the rest:

```ember,fixed
enum Color:
    Red
    Green
    Blue

fn weight(c: Color) -> int:
    match c:
        Color.Red:
            return 1
        Color.Green:
            return 2
        Color.Blue:
            return 3
    return 0

fn main():
    println(weight(Color.Blue))
```
