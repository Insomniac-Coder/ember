# L2001 — unnecessary clone

```ember,fails
fn take(owned s: String) -> int:
    return s.len()

fn main():
    name = String.from("hello")
    copy = name.clone()
    println(take(copy))
```

```text
warning[L2001]: `name` is cloned, then never used again
```

## Why

A clone of text or a list allocates and copies every byte. When the original is never read again,
the copy buys nothing: moving the original hands over the same bytes for free, and the original's
own drop, which the clone left to happen later, does not happen at all.

## The fix

Pass the value itself. `ember lint` reports this only where nothing reads the original afterwards,
so the move is always allowed.

```ember,fixed
fn take(owned s: String) -> int:
    return s.len()

fn main():
    name = String.from("hello")
    println(take(name))
```
