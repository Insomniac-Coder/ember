# L2001 — unnecessary `copy of`

```ember,fails
fn take(owns s: String) -> int:
    return s.len()

fn main():
    name = String.from("hello")
    kept = copy of name
    println(take(owns kept))
```

```text
warning[L2001]: `name` is copied, then never used again
```

## Why

A copy of text or a list allocates and copies every byte. When the original is never read again,
it buys nothing: moving the original hands over the same bytes for free, and the original's
own drop, which the copy left to happen later, does not happen at all.

## The fix

Pass the value itself. `ember lint` reports this only where nothing reads the original afterwards,
so the move is always allowed.

```ember,fixed
fn take(owns s: String) -> int:
    return s.len()

fn main():
    name = String.from("hello")
    println(take(owns name))
```
