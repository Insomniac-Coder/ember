# E0001 — a source file that is not UTF-8

A file saved by an editor set to Latin-1, with `é` stored as the one byte
`0xE9` (written `<0xE9>` here, since this page is UTF-8):

```ember,fails
fn main():
    println("caf<0xE9>")
```

```text
error[E0001]: `main.em` is not valid UTF-8
  = help: source files are UTF-8; save it in that encoding
```

## Why

Ember source is UTF-8 (`[LEX-1]`), so that a file means the same text on every
machine and every identifier has one spelling (`[LEX-12]`). A byte sequence that
is not UTF-8 has no meaning as text, and guessing an encoding would give the
same file different meanings on different machines. The check covers every file
a build reads: the one named on the command line and each module it imports. A
byte-order mark at the start is accepted and ignored.

## The fix

Save the file as UTF-8, where `é` is two bytes:

```ember,fixed
fn main():
    println("café")
```
