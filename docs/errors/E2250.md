# E2250 — format spec does not apply to the value's type

```ember,fails
fn main():
    name = "Ann"
    println(f"{name:d}")
```

```text
error[E2250]: format spec `:d` does not apply to `str`
```

## Why

An f-string's format spec is Python's mini-language, and each part of it means
something only for some types: `d`, `x` and `b` write integers, `f`, `e` and
`%` write numbers as decimals, `,` groups digits, and a precision shortens
text or sets a float's digits. A spec that names a type the value is not has
no meaning, so the compiler says so rather than guess. The message names the
spec and the type, and the note says which part does not apply.

## The fix

Use a spec for the value's type, or convert the value first:

```ember,fixed
fn main():
    name = "Ann"
    println(f"{name:>6}")
```
