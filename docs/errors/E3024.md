# E3024 — a field would borrow another field of the same value

```ember,fails
@view
struct Parsed:
    text: String
    head: str

fn main():
    t = "hello world".to_string()
    p = Parsed(t, t[0..5])
    println(p.head)
```

```text
error[E3024]: `t` would be moved into this value while another of its fields borrows it
```

## Why

`head` is a view of `t`'s bytes, and `t` moves into the same value. A value can
be moved anywhere, and a move would carry `text` with it while `head` still
points where it was: a value cannot hold an owner and a view into it.

## The fix

Store a position in the owner instead of a view of it, and make the view when
it is needed:

```ember,fixed
struct Parsed:
    text: String
    head_end: int

fn main():
    t = "hello world".to_string()
    p = Parsed(t, 5)
    println(p.text[0..p.head_end])
```

A `Handle` into a collection works the same way. Or keep the owner outside the
value and let the value hold only the view.
