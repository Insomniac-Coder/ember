# E2042 — `Float` is implemented only by `f32` and `f64`

```ember,fails
from std.math import Float

struct Money:
    cents: int

extend Money implements Float:
    fn sqrt(self) -> Money:
        return self

fn main():
    println(Money(100).cents)
```

```text
6 | extend Money implements Float:

  = help: write the generic code over your own interface, or convert to `f64`
  = note: `Float` is implemented by `f32` and `f64` only [STD-27]
```

## Why

`std.math.Float` is the bound of the generic float functions (`sqrt`, `lerp`,
`smoothstep`, …). A body bounded by it may write a literal where a `T` is
wanted, `x * 0.5` or `1.0 / x.sqrt()`, and the literal becomes a `T`. That is
something `f32` and `f64` can promise and no other type can: there is no way
to turn `0.5` into a `Money`. So the interface is closed, and the functions
written over it stay correct for every type that meets it.

## The fix

Give the type its own methods, or write the generic code over an interface of
your own; to use the float functions, convert to `f64`:

```ember,fixed
struct Money:
    cents: int

extend Money:
    fn halved(self) -> Money:
        return Money(self.cents // 2)

fn main():
    println(Money(100).halved().cents)
```
