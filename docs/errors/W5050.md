# W5050 — a grade claimed with no evidence

```ember,fails
unsafe overlay c "zlib.h":  # SAFETY(ffi): each entry matches its declaration in the header
    @grade(instrumented)
    @ffi(effects=[FFI])
    fn zlibVersion() -> borrowed nul_terminated from(static)

fn main():
    pass
```

```text
warning[W5050]: `instrumented` is claimed with no evidence: the fact stays asserted
 --> page.em:2:5
  |
2 |     @grade(instrumented)
  |     ^^^^^^^^^^^^^^^^^^^^
  |
  = note: `instrumented` needs a run of `ember test --instrument-ffi` that observed it, recorded under the manifest's `[ffi] evidence` (`.ember/ffi-evidence`) [TCB-1]
  = note: writing a grade never raises it [TCB-2]
```

## Why

Every fact an overlay states about foreign code is graded by how much stands
behind it: **asserted** (someone wrote it), **instrumented** (a test run saw no
counterexample on the paths it exercised), **checked** (verified against the
header) or **proven**. The trusted-base report (`ember tcb`) shows each fact
with its grade, so a reader knows which assumptions are only someone's word.
If writing `@grade(proven)` were enough to make a fact proven, the report would
show whatever its authors wished, and the grades would mean nothing. So a
grade above asserted is a claim the evidence must back; until it does, the fact
stays asserted, and this warning says so. `[TCB-1]` makes it the error `E5050`
under `ember build --require-evidence` and `ember tcb --require`.

## The fix

Produce the evidence the grade names, or claim no more than asserted:

```ember,fixed
unsafe overlay c "zlib.h":  # SAFETY(ffi): each entry matches its declaration in the header
    @grade(asserted)
    @ffi(effects=[FFI])
    fn zlibVersion() -> borrowed nul_terminated from(static)

fn main():
    pass
```
