# E7010 — a parallel loop writes a shared place

```ember,fails
fn main():
    values = [1, 2, 3, 4]
    total = 0
    @parallel
    for i in 0..4:
        total += values[i]
    println(total)
```

```text
error[E7010]: the parallel loop writes `total`, which its chunks share
```

## Why

A `@parallel` loop's chunks run at once, on several threads, so its iterations
must not depend on each other. Each one may write only an element of a
`MutSpan` or an `SoA` column, reached at the loop's index plus a constant, and
its own locals. A variable of the code around the loop is one place every chunk
would write at once; so is an element reached at an index that is not `i` plus
a constant, or a span handed to a call, which may write any element of it.
`break` and `return` would stop iterations that may already have run.

## The fix

Declare a variable every iteration adds to as a reduction: each chunk has its
own copy, and the copies are combined in order after the loop:

```ember,fixed
fn main():
    values = [1, 2, 3, 4]
    total = 0
    @parallel(reduce=[total: +])
    for i in 0..4:
        total += values[i]
    println(total)
```

Write results to the iteration's own element (`out[i] = …` through a
`MutSpan`), use an `Atomic`, or split the data with `chunks_mut`.
