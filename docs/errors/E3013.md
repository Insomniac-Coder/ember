# E3013 — cannot move out of a reference

```ember,fails
struct Inner:
    pub n: i32

    fn drop(mut self):
        println(self.n)

struct Outer:
    pub inner: Inner

fn main():
    o = Outer(Inner(1))
    r: ref Outer = ref o
    x = r.inner
    println(x.n)
```

```text
error[E3013]: cannot move out of a reference
  --> page.em:13:9
   |
13 |     x = r.inner
   |         ^^^^^^^ moved out here
   |
   = help: borrow it instead of moving it; if the function needs ownership, take an `owned` parameter
   = note: moving out of a `ref`/`ref mut` is forbidden [EXP-6]; the referent still owns the value and drops it
```

The same code reports `cannot move out of a borrowed parameter` when the
place is a borrowed (`[FN-1]`) parameter rather than a reference: a borrowed
parameter reads through a `ref`, so moving out of it is the same double
destruction across the call boundary instead of within one frame.

## Why

A move hands ownership to a new owner, who drops the value when its own
life ends — but the old owner drops it too. Through a reference the referent
is that old owner; through a borrowed parameter the caller is. Either way
the destructor runs twice for one value, which for anything owning a buffer
is a double free with no `unsafe` in the program. Copying or borrowing
leaves the source intact, so reads through a shared borrow stay legal and
only the move is refused.

## The fix

Borrow the value instead of moving it, or take ownership explicitly:

```ember,fixed
struct Inner:
    pub n: i32

    fn drop(mut self):
        println(self.n)

struct Outer:
    pub inner: Inner

fn steal(owned o: Outer):
    x = o.inner
    println(x.n)

fn main():
    o = Outer(Inner(1))
    steal(o)
    println(99)
```
