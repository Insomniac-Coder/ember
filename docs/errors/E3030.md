# E3030 — retired: a once-only closure is required to be reusable

`E3030` is no longer emitted. It refused a function that gives one of its captures away, where it may run twice.

Since 0.9.20 it is folded into `E3013`: "this function gives `values` away, so it can run only once, and `twice` may run it more than once"; the help takes the parameter `owns f: once fn(...)`, or hands over a copy each time (`copy of values`).
