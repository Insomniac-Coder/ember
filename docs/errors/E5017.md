# E5017 — a struct with a flexible array member is used by value

```c,file=packets.h
#include <stdint.h>
struct Packet { uint8_t count; int64_t values[]; };
```

```ember,fails
import c "packets.h"

fn copy_of(packet: ref c.Packet) -> c.Packet:
    return packet

fn main():
    pass
```

```text
error[E5017]: `c.h_packets.Packet` ends with a flexible array member, so it is used by value nowhere, not in a function's result
```

## Why

A C struct that ends with a flexible array member (`int64_t values[];`) is only its header: its
elements follow it in an allocation C sized for them, and the struct's own size counts none of them.
A copy of it by value — a parameter, a result, a local, a field — would take the header and leave
the elements behind, and any read of them through the copy would run off its end. So the struct is
unsized: it lives where C put it, behind a reference or a pointer, and its elements are reached
through it with `tail(n)`.

## The fix

Hold it behind a reference:

```ember,fixed
import c "packets.h"

fn count_of(packet: ref c.Packet) -> u8:
    return packet.count

fn main():
    pass
```
