# E2231 — `yield` while a `@must_drop` value is live

```ember,fails
import std.thread

gen fn spawning(xs: Span[int]) -> Generator[int]:
    with s = thread.scope():
        s.spawn(fn() => println(xs.len()))
        yield 1

fn main():
    data = [1, 2]
    for x in spawning(data):
        println(x)
```

```text
error[E2231]: `s`, a `@must_drop` value, is live across this `yield`
 = help: close its scope before the `yield`
```

## Why

A `@must_drop` value is one whose `drop` a safety guarantee depends on: a
`thread.scope()` joins its threads when it ends, which is what lets them borrow
the caller's data (`[THR-6]`). A suspended generator can be forgotten or leaked
like any other value, and then its locals' `drop`s never run. A scope live
across a `yield` could so leave threads running over data that is gone
(`[CORO-13]`).

## The fix

Close the scope before the generator suspends:

```ember,fixed
import std.thread

gen fn spawning(xs: Span[int]) -> Generator[int]:
    with s = thread.scope():
        s.spawn(fn() => println(xs.len()))
    yield 1

fn main():
    data = [1, 2]
    for x in spawning(data):
        println(x)
```
