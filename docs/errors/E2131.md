# E2131 — array length must be a constant

```ember,fails
fn main():
    size: usize = 4
    xs: [i32; size] = [0; 4]
    println(xs[0])
```

```text
error[E2131]: `size` is not a constant, so it cannot be a const argument
 --> page.em:3:15
  |
3 |     xs: [i32; size] = [0; 4]
  |               ^^^^
  |
```

## Why

The length of a `[T; N]` is part of its type, and the size of the value is known when compiling (`[TYP-1]`).
Array lengths are evaluated during compilation (`[CT-1]`), so a number that is only known while the program
runs cannot be one.

## The fix

Make the length a `const`, or use an `Array[T]`, whose length is a run-time value:

```ember,fixed
const SIZE: usize = 4

fn main():
    xs: [i32; SIZE] = [0; SIZE]
    println(xs[0])
```
