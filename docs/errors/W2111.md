# W2111 — `virtual` has no effect in a final class

```ember,fails
class FinalThing:
    virtual fn tick(self):
        pass

fn main():
    println(1)
```

```text
warning[W2111]: `virtual` has no effect in a final class
```

## Why

A final class cannot have subclasses, so no derived class can override or
dispatch through this method. The declaration is accepted for compatibility,
but the warning identifies a dispatch promise that has no observable effect.

## The fix

Remove `virtual` from a method in a final class, or mark the class `open` when
subclassing and virtual dispatch are part of the design.

```ember,fixed
class FinalThing:
    fn tick(self):
        pass

fn main():
    println(1)
```
