# W2111 — retired: `virtual` in a final class

`W2111` is no longer emitted. It once warned that `virtual` has no effect in a final class.

A `virtual` method in a class that cannot be subclassed (neither `open` nor `abstract`) is now refused (`E2112`), so the
warning went, and the number is not reused.

## Why

The rule refuses what the warning only noted: a promise of dispatch no subclass can use.
