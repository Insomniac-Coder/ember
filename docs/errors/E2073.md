# E2073 — `len` of a string

```ember,fails
fn main():
    name = "héllo"
    println(len(name))
```

```text
error[E2073]: `len` of a string
```

## Why

Python's `len("héllo")` is 5: it counts characters. Ember's strings are UTF-8,
and `s.len()` is their length in bytes, which is what indexing and slicing
use: `"héllo".len()` is 6, because `é` takes two bytes. `len(s)` would have to
pick one of the two meanings, and either would surprise someone, so it asks.

## The fix

Say which count you mean:

```ember,fixed
fn main():
    name = "héllo"
    println(name.len())
```

`s.char_count()` is Python's count of characters.
