## 3. The specification, and the rule that governs it

**`docs/spec-source/as-received/Ember_v0.8.3_spec.md` is the owner's file, is
never edited, and hashes to `2bdffee6510b8668cf828185266efedb`.**

`docs/spec-source/ember-spec.md` is the normative copy — v0.8.3_Hardened_1.
`docs/spec/` is generated from it. `Ember_v0.8.3_Hardened_1.md` is a frozen
snapshot, so Hardened_2 diffs against this rather than against the original.

**The rule, which cost two withdrawn amendments to learn:** the specification is
the contract and is never altered to make the compiler agree with it. Where the
two disagree, the compiler moves. Where the *document* disagrees with itself it
goes to the owner, and **neither side moves** until it is ruled. Every edit
declares one of five classes and a hardening admits only four; the fifth — an
owner-approved semantic change — forces a language revision instead.

Both failures had the same shape, and it is the thing most worth carrying
forward: **the analysis was right, and the answer went into the normative text
instead of the ledger.** A4 wrote a determination about `E3064` into `[LT-2]`.
A6 wrote an unruled reading of `[FN-1]` into the rule, with the words "not yet
ruled on by the owner" directly above it in the ledger — the document carries the
sentence, not the caveat.

`tools/hardening_check.py` now catches an *undeclared* edit mechanically. It
would not have caught either of those, because both were declared: it is a floor,
not a substitute for the owner's review. On its first run it found ten
undeclared differences, all real.

## 4. What the fix list produced

Every item is done or recorded. The ones that changed the compiler:

* **`[SPN-1]`** — the coercion takes a borrow. It had been a use-after-free
  reachable from Safe Ember. One producer (`view_of`), plus `verify_views`, a
  typed MIR pass holding the invariant that no view arrives without a loan.
* **`[CLO-3]`** — a `fn(A) -> R` parameter is an implicit generic bounded by
  `Callable`, monomorphised per argument type; a capturing lambda is an anonymous
  struct of its `[CLO-2]` captures. `[CLO-4]` then needed **no code at all**: the
  environment holds real borrows, so the borrow checker already rejects mutating
  a captured container.
* **`[RNG-4]`** — intervals, not constants. The fact carrying the weight is that
  a value at a range type is in its declared range (`[RNG-9]`), which is what
  gives `[RNG-10]`(d) anything to contain.
* **`[LT-2]`/`E3064`** — reachable all along, and reported as shape B3. The
  rejection was right; the *advice* was wrong, and that is why it mattered.
* **`[BRW-1]`** — a write through a shared `ref` was caught only by the C
  backend emitting `const`. Aliasing-XOR-mutability was being upheld by luck.
* **`[GRM-23]` → `E0104`**, **`[MAN-3]` → `E9010`**, **`RangeError`** as a
  prelude type, **field visibility** centralised on one check, **`extern "C" fn`**
  and **`extern class`** parsed.

## 5. Where to pick up

`docs/MIGRATION-0.8.3.md` has the route. The next block, in dependency order:

1. **Interior mutability** — `Cell`/`RefCell` (`[CELL-*]`) and `Arena`
   (`[ARN-*]`) all wait on one missing primitive. `[CELL-1]`'s `set` takes `self`
   (a *shared* borrow) and writes; `[ARN-1]`'s `alloc*` methods do the same.
   Amendment A13 records the design and its distinction: they share the
   implementation concern, not the concept — `Cell` replaces a whole value and
   hands out no reference, `RefCell` asks `[BRW-1]`'s question at run time
   against a counter, `Arena` proves a region statically. **Decide the primitive
   once, for all three.**
2. **`[DIA-7]`'s shape catalogue with `tests/ui/` snapshots** — a Phase 2 exit
   criterion. `compiler/ember_diag/src/shapes.rs` holds every shape; `tests/ui/`
   is empty, and `[DIA-13]` wants a rendered snapshot per shape plus
   `[PHIL-8a]`'s `.fixed.em` companion.
3. **`[TXT-*]`** the text model, and **`[CTL-3b]`/`[CTL-3c]`** guaranteed
   iteration lowering with the emitted-C assertions.
4. **`[DSJ-*]`** — deliberately not started. `[DSJ-2]` attaches the proof "to the
   **returned values**, not to a program point", and the type system has nowhere
   to carry a fact on a value. Half of it is the API with the fact unenforced,
   which is the half that matters.

## 6. Traps paid for

* **A stale binary makes a gate lie.** `tools/error_pages.py` preferred
  `target/release/` over `debug`, so it validated pages against a compiler from
  an earlier session and reported a good page as broken. Newest wins now, and the
  gate says which it used.
* **An assertion can satisfy itself.** A `compile-fail` case writes its expected
  code on the line that provokes it, and the renderer echoes that line — so
  `stderr.contains("E1050")` matched the test's own annotation. Every trailing
  expectation asserted nothing, twice over, because the harness did not parse
  them either. Found by writing a case with a deliberately wrong code and
  watching it pass.
* **A Python line-continuation eats a Rust `\`.** Two help strings shipped with
  eighteen spaces mid-sentence. Write Rust through the Write tool, never a shell
  heredoc.
* **A checker that knows one shape of a rule reports thirty false positives.**
  The document states a rule in at least four shapes; a test tight enough to
  reject every citation also rejected `**Integer overflow** `[TYP-8]`:`.
* **A new value-producing form must be walked through every analysis by hand.**
  D-022 was found by *asking* whether the borrow checker saw the view, not by a
  test failing.
* **CRLF.** The Edit tool writes CRLF on this host while `.gitattributes` pins
  LF. Normalise before every commit.
